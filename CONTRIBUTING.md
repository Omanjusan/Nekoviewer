# Contributing

Thank you for your interest in Nekoviewer.

## Basic Policy

- Bug reports and feature requests are welcome on [GitHub Issues](https://github.com/Omanjusan/Nekoviewer/issues).
- Pull requests (PRs) are not actively sought. They are handled on a best-effort basis and are not necessarily merged. Replies may take some time.
- This project also serves as an experiment in how far AI coding can go. Design and specification decisions are made by the author.

## About Issues

Please report bugs and requests as Issues. Any language is fine, since reports are run through translation.

For bug reports, the following information helps with investigation:

- Nekoviewer version and OS (Windows / Linux)
- Distribution type (exe / Flatpak / AppImage / source build)
- What the problem is, and how to reproduce it
- If possible, logs or screenshots

When attaching files to reproduce a problem, please use files that contain no copyrighted material or personal information. If possible, reproduce the problem with a self-made archive containing dummy images. Files that show real people, or that contain information that can identify a real person, may be removed without notice.

For reporting security problems, please also see [SECURITY.md](SECURITY.md).

## About Pull Requests

PRs like the following are fine to send:

- Bug fixes with a small scope and a clear purpose

If you do send a PR, please keep the following in mind:

- Target the `develop` branch
- Keep each PR focused on a single purpose
- Make sure the build (`cargo build`) and the tests (`cargo test`) pass
