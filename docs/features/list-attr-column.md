# リストの「エラー列」「属性列」と、★・訪問回数の編集

リスト表示（[explorer-view-modes.md](explorer-view-modes.md)）に、カードにあるマーカーを列として並べる「エラー列」「属性列」と、
評価（★）・訪問回数を行の上から直接直す「＋－」を足した機能。

実装:
[list_view.rs](../../src/view_explorer/list_view.rs)（列の定義・行高さ・セルの配置）、
[list_attr_ui.rs](../../src/view_explorer/list_attr_ui.rs)（エラー列・属性列のスロット描画。お気に入りの引き当てはカードと共通）、
[list_edit_ui.rs](../../src/view_explorer/list_edit_ui.rs)（＋－ボタンの描画・押下・保存・並びへの反映）、
[list_edit_lock.rs](../../src/view_explorer/list_edit_lock.rs)（編集のロックと自動ロック）、
[spread_state.rs](../../src/spread_state.rs)（評価・訪問回数の加減算）。

## 列構成

左から エラー｜重複｜ファイラー｜サムネ｜名前｜（場所｜完全比較）｜サイズ｜更新日時｜評価｜訪問回数｜属性。
エラー列と属性列は**固定幅**でドラッグできない。列幅の保存（`explorer_list_cols`）は従来の6個のままなので、既存の列幅は変わらない。
類似ファイル一覧・似ている画像ビューでも、通常のリストと同じように出す。

### 固定スロット方式

マーカーは「あるものを左へ詰める」のではなく、種別ごとに**決まった位置**に置く。該当しないスロットは空けたままにして、
行どうしを縦に見比べられるようにする（カードの保存設定マーカーと同じ考え方）。

| 列 | 幅 | スロット（左から） |
|---|---|---|
| エラー | 44px | 赤X（無効ZIP／サムネのデコード失敗）｜⚠（大元のマウントに到達できない） |
| 属性 | 126px | L/R（見開き）｜S（並び順を保存）｜T（サムネを指定）｜B（しおり）｜お気に入り×3 |

- 重複マーカーと「？」は、従来どおり先頭の「重複」列に置く（属性列には入れない）。
- 両方に当てはまる行は、エラー列の2つとも出す。ホバーで理由を出す。
- お気に入りは、付いた順に先頭の3つまで。**4つ目以降はホバーの一覧**で見る（スロット内に目印は出さない）。
  フォルダを指定せず登録しただけのものは、既定色の「★」1つ。ホバーの一覧は、スロットに入らない分も含めた全件。
- 属性列の見出しはクリックしてもソートしない。

## ★・訪問回数の編集（リスト専用）

### ロック

- ツールバーの `[サムネ一致閾値▼]` の右に、トグルボタンを置く。ラベルは今の状態を明記する:
  「★/訪問回数の編集ロック」（既定）／「★/訪問回数の編集アンロック」。アンロック中だけ背景がオレンジ。
- 普段はロック状態で、＋－は出ない。解除はリスト表示のときだけ押せる（カード中は押せない表示）。
- 解除は保存しない。起動時は必ずロック。
- **次のとき自動でロックに戻る**: フォルダ移動／左ペインのタブ切替／お気に入り・検索・仮想フォルダ・類似ファイル一覧への出入り／カード表示への切替。
  個々の移動処理ではなく、毎フレーム「今の表示」を前のフレームと比べて検出する（書き忘れを構造的に防ぐ）。
- ロック中の＋－は存在しないので押せない。

### 行の見た目

- 解除中は**全行を一律に高く**する（下限46px。元から高いLなどはそのまま）。仮想スクロールは全行同じ高さが前提のため。
- 評価・訪問回数のセルが2段になる。上段に今の値、下段に `[－][＋]`。
- サムネ列の幅・文字の大きさ・サムネの高さは元の行高さのまま動かさない（横方向のレイアウトが動かない）。
- 行の高さが変わるとき、見ていた位置（選択行が見えていればそれ、無ければ上端の行）が同じ高さに残るようスクロールを補正する
  （既存の `layout_anchor.rs`。ロックし直すと元に戻る）。キーボードの上下移動も新しい行高で計算される。

### ＋－の規則

| 対象 | ＋ | － |
|---|---|---|
| 評価 | 0.5刻み。未評価からは0.5から始まる。★5.0で止まる | 0.5の次は未評価。未評価で止まる |
| 訪問回数 | 1ずつ。99999で止まる（既にそれを超えている実績は＋が効かないだけで値は変えない） | 1ずつ。0で止まる |

- 端まで動かした側のボタンは灰色で、押しても何も起きない（選択や起動にも回らない）。
- 生画像は評価の対象外なので、評価の＋－は出さない（「-」のまま）。訪問回数の＋－は出す。
- 訪問回数を**0にしたときだけ**、最終訪問日時も「記録なし」に戻す。それ以外の＋－では最終訪問日時に触らない。
  0にしてもレコードは消さない（評価は残る）。
- 増減は読み取りと書き込みを同じトランザクションで行う（連打しても取りこぼさない）。評価と訪問回数は別々に書き、互いに触らない。
- お気に入り・検索タブなどの横断一覧でも使える（フルパスからフォルダとファイル名に分けて書く）。
- 保存に失敗したらトーストを出す。

### 並びへの反映

- 編集中は**行を動かさない**。評価・訪問回数で並べていても、評価フィルタを使っていても、押した行はその場に残る（連打できる）。
- **ロックし直した時点**（ボタンで戻す・自動で戻る）で、並びと絞り込みを作り直す。選択は同じファイルのまま保つ。
  並びが評価・訪問回数に依らず、評価フィルタも無いときは、何もしない。

### 「未訪問」

訪問回数が0のときは、数字ではなく「未訪問」と表示する（一度も開いていない場合も、手動で0に戻した場合も同じ）。
リストの訪問回数セルとカードの訪問回数の行の両方。リストでは薄い色。カードは「訪問回数：N回」の行全体が「未訪問」に置き換わる。

## 手動テスト手順

| # | 操作 | 期待 | OK |
|---|---|---|---|
| 1 | リスト表示にする | 最左に「エラー」、最右に「属性」の列。どちらも境界をつかんでも幅が変わらない | [ ] |
| 2 | 既存の列幅を調整してあるまま起動する | 他の列の幅が保たれている（リセットされない） | [ ] |
| 3 | 無効なZIP（画像なし）を含むフォルダを開く | その行のエラー列に赤X。ホバーで「画像が含まれない無効なZIPです」 | [ ] |
| 4 | サムネがデコードできないファイルがある | 赤X。ホバーで「<拡張子>デコード失敗」 | [ ] |
| 5 | ネットワークに到達できないマウント上のフォルダを開く | ⚠が赤Xの右のスロットに出る。ホバーで説明 | [ ] |
| 6 | 見開き保存・並び順保存・サムネ指定・しおりのあるファイル | 属性列の L/R・S・T・B の位置にそれぞれ出る。無いものは空欄のまま詰まらない。ホバーで説明 | [ ] |
| 7 | お気に入りに入れたファイル（フォルダ指定あり／なし） | 属性列のお気に入りスロットに、色つき文字／既定色の★ | [ ] |
| 8 | 1ファイルを4つ以上のお気に入りフォルダに入れる | スロットには3つまで。ホバーで全件が一覧される | [ ] |
| 9 | お気に入り一覧・検索結果（横断一覧）、類似ファイル一覧 | 属性列・エラー列が同様に出る | [ ] |
| 10 | カード表示でマーカーを確認する | 従来どおり（見た目が変わっていない） | [ ] |
| 11 | ツールバーのトグルを見る | 「★/訪問回数の編集ロック」。リスト表示のときだけ押せる | [ ] |
| 12 | ロック中の評価・訪問回数セル | ＋－が出ない。行の高さも従来どおり | [ ] |
| 13 | トグルを押す | ラベルが「…アンロック」に変わり、背景がオレンジ。全行が一律に高くなり、2段のセルに `[－][＋]`。見ていた行がずれない | [ ] |
| 14 | 解除中、リストのサイズS/M/L/サムネ無しを切り替える | どれも46px以上に揃う。サムネ列の幅は変わらない | [ ] |
| 15 | 未評価の行の評価の＋を押す | ★0.5。続けて押すと0.5刻みで増え、★5.0で＋が灰色になる | [ ] |
| 16 | －を押し続ける | 0.5の次に「未評価」になり、－が灰色になる | [ ] |
| 17 | 訪問回数の＋－を押す | 1ずつ増減。0で－が灰色。0のとき「未訪問」と表示 | [ ] |
| 18 | 訪問回数を0にして、ビューアーで開き直す | 訪問1回・最終訪問が今に更新される | [ ] |
| 19 | 生画像の行 | 評価は「-」のままで＋－が出ない。訪問回数の＋－は出る | [ ] |
| 20 | 評価で並べている状態で、押した行 | 押した行は動かない。連打できる | [ ] |
| 21 | 20の状態でトグルを押してロックに戻す | 並びが作り直される。選択は同じファイルのまま | [ ] |
| 22 | 評価フィルタ（例: ★3.0以上）の状態で評価を下げて、ロックに戻す | ロックに戻した時点で、行が一覧から外れる（それまでは残る） | [ ] |
| 23 | 解除中にフォルダを移る | 自動でロックに戻る。ラベルとオレンジが戻る | [ ] |
| 24 | 解除中に左ペインのタブを切り替える／お気に入りを開く／カード表示にする | いずれも自動でロックに戻る | [ ] |

| 26 | お気に入り・検索の横断一覧で解除して＋－を押す | 値が変わり、ビューアーで開いても同じ値 | [ ] |
| 27 | ＋－を押した行のクリック／ダブルクリック | 押したボタンだけが効く。選択の移動も、ファイルが開くことも起きない。ボタン以外のクリックは従来どおり | [ ] |

| 30 | 日本語以外の表示言語（English/中文） | 列見出し・トグル・ホバー・「未訪問」が翻訳されている | [ ] |
