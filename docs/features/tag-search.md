# タグ検索タブ

付けたタグから、フォルダをまたいでファイルを探すタブ。左ペインのタグ一覧でタグを有効にするたびに、
全ての有効タグを持つファイルへ絞り込み、中央のカード／リストに並べる。

## 画面

- タブは「仮想フォルダ」の右隣（左ペインのタブ列2行目の末尾）。
- 左ペインはツリーの代わりにタグ一覧。カテゴリごとに見出しとチップを並べる。メインカテゴリが先頭で、
  その先頭に「（未設定）」の疑似チップがある。
  - 有効のチップはカテゴリ色で塗りつぶし、無効はカテゴリ色の枠線だけ。
  - 単一選択のカテゴリは、見出しの右に「S」マークが付く（メインカテゴリは常に単一選択）。
    中のチップは同時に1つしか有効にできない。別のチップを押すと入れ替わり、有効なチップを押し直すと無効に戻る。
    複数選択のカテゴリは、いくつでも有効にできる。
- 左ペインと中央の境目は、中央のグリップをドラッグして幅を変えられる（180〜600px、既定200px）。
  このタブだけの機能で、他のタブは200px固定。幅は state ファイルの `tab_tag_search_width` に保存する。
  ウィンドウが狭いときは左の幅を優先し、右のタグパネルが先に狭まる。
- 中央は、有効タグが無い間はガイド文だけ。1つ以上あると通常の一覧になる（カード／リストの切替、
  フィルタ行、ダブルクリックで開く、はそのまま使える）。
- 見出しは「N件（検索中…）」。前回の確認で見つからなかったファイルは一覧から外し、
  「確認できないファイルが別にN件あります」と添える。

## 検索の規則

- 対象は spread DB のファイルID台帳の全件。フォルダのサムネDB（cache.redb）の有無やサムネ生成の有無は関係ない。
- 有効タグの組み合わせは全部AND。
- 「（未設定）」は、メインカテゴリのタグを1つも持たないファイルに一致する。タグの記録が無いファイルも含む。
  他のタグとのANDも可能（例: 未設定 かつ 属性タグA）。
- ネガティブ tier も普通のタグと同じ扱い（除外条件にはならない）。
- 有効タグの状態は、アプリを動かしている間だけ覚える。終了時に保存しない（起動後は全て無効）。
- ID未解決で、旧v1（パスキー）にだけタグが残っている行は対象外（実体が無いファイルの残骸のため）。

## 動作

- 走査は専用スレッドで行い、ヒットを200件ずつ一覧の末尾に追記する（到着順）。完了したときに1回だけソートする。
- チップを切り替えるたびに、古い走査を打ち切って最初からやり直す。タブを出るときも打ち切る。
- 一覧は、お気に入りや検索の横断一覧と同じく、中央の `archives` を差し替える方式。タブを出ると、
  実フォルダの表示に戻る。このタブにいる間は、実フォルダの読み込みで一覧を上書きしない
  （`start_scan` は何もしない）。
- パスはID台帳の現在のパスキーのまま。ファイルが実在するかの確認（stat）は走査ではしない。
  サムネは表示中のセルだけが要求する（横断一覧の既存の仕組み）。

## 実装メモ

| 場所 | 内容 |
|---|---|
| `tag_search.rs` | 走査エンジン。`TagQuery`（AND判定・未設定判定）、`spawn`（専用スレッド、チャンク送信、Dropで打ち切り） |
| `file_identity::for_each_record_tx` | ID台帳を1件ずつ渡す（打ち切り可）。全件をメモリに載せない |
| `file_settings::effective_tags_tx` | IDの現在有効なタグだけを読む（未移行のときだけ旧v1を引く） |
| `view_explorer/tag_search_ui.rs` | タグ一覧、グリップ、一覧の差し替え・走査の開始と終了・結果の受け取り、見出し |
| `FolderPaneTab::TagSearch` | タブの列挙子。`SavedTab::TagSearch`（`tag_search`）で最後に開いたタブとして保存される |
| `tab_positions.tag_search_left_width` | 左ペイン幅。位置ではなくレイアウトなので、「前回フォルダに復帰」オフでも消えない |

## 制限

- 数十万件規模の実データでの速度は未計測。走査はバックグラウンドだが、ヒットを追記するたびに
  フィルタを全件で再計算するため、ヒットが非常に多いと重くなる可能性がある。
- 確認済みのレコードでも、オフラインのボリュームのファイルは一覧に出て、サムネが失敗する。
- タグ管理画面でカテゴリを単一選択へ切り替えたとき、すでに複数が有効でもその場では直さない。
  次にそのカテゴリのチップを押したときに排他になる。
- 起動時にこのタブが復元されても、有効タグは無いので、ガイド文の表示から始まる。

## 手動テスト手順

タグを付けた複数のフォルダのファイルを用意して試す（メイン・属性・複数選択／単一選択のカテゴリを含める）。
