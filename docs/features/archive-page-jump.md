# アーカイブ内ページジャンプ（サムネバー／エントリリストのクリック＋サムネバー切替）

アーカイブ閲覧中に、1ページ目から20ページ目へ飛ぶといった「飛ばし閲覧」をマウスだけで行うための機能。
専用のシークバーは作らず、既存のサムネバーと左エントリリストにクリックジャンプを足した。

## 仕様

### ジャンプ手段

| 手段 | 操作 |
|---|---|
| サムネバー | サムネをクリック → そのページへ。スワイプ（つかんで動かす）ではジャンプしない |
| 左エントリリスト | 左上ホバーで出る一覧の行をクリック → そのページへ（サムネ表示なし） |

- 見開きでは、クリックしたページ N **を含む見開き**に着地する。ページずれ（offset: -1/0/+1）は維持する。
  - offset=+1 で先頭ページ(0)を指定した場合のみ、+1 では表せない（lo=-1）ため仮想左（-1）へ倒す。
- 単ページでは offset を 0 に戻し、そのページそのものを表示する。
- 見開きの仮想スロット（先頭の -1／末尾の total）をクリックした場合は、端の実ページへ丸める
  （仮想スロットは現在地がそこにあるときだけ出るため、実質その見開きのまま）。
- バーの表示・非表示は、ポインター侵入トリガー（下記「サムネバーの表示」）。

### エントリリストの表示・スクロール

- 本体は「メニューバー＋タイトルバー（自動ハイドのオーバーレイ）の下」から始まる（サムネバーと同じ上端確保 `top_overlay_inset`）。
  幅180px。**オーバーレイ方式**（領域を確保しないので、表示しても本画像は縮まない・ずれない）。パレットより先に描くため、ツールボックスが前面になる。
  背景はパネル色の **50%透過**（`ENTRY_LIST_BG_OPACITY`）。リスト全体にクリックの土台があり、行の隙間のクリックも背面の画像（ページ送り）へ抜けない。
  左端のページ送りゾーン・サムネバーとは、リストが出ている間はリスト優先で排他。
- リスト表示中にページが変わったら（行クリックのジャンプ・キー送りなど）、現在行まで滑らかにスクロールして着地する。
  行は中央へ寄るが、先頭・末尾付近は範囲内にクランプされ中央までは行かない。表示を始めた瞬間の初期位置だけは即時。
- 行の文字には影を付ける（黒の半透明を1pxずらして下に敷く。背景が50%透過で背後の画像が透けても読めるように）。
- スワイプ（マウスでつかんで動かす）でもスクロールできる。サムネバーと同じ仕組みで、離した後は慣性で流れ、一定以上動かすと行のクリック（ジャンプ）は発火しない。
  スワイプ中（リスト上で押したボタンが押されている間）は、ポインターがリスト外へ出てもリストを隠さない。離してリスト外なら隠れる。
- リスト上のホイールはリストのスクロール専用で、ページ送り・ファイル送り・虫眼鏡入場へは渡さない。
- リストを隠した時点で、ホイールで動かした位置と現在行へのスクロール記録をリセットする（再表示時は現在ページが中央）。

### サムネバーの位置（画面端への密着と上配置の特別仕様）

- バーは画面の端に**完全に寄せる**（余白0）。バーの矩形の上のホイールは、必ずバー専用（ページ送り・ファイル送りには渡らない）。
  配置の基準は `ui.clip_rect()`（余白を含むパネル全体）。`CentralPanel` の既定は内側余白8pxがあり、`ui.cursor()`／`available_size()` 基準（`viewport_rect`）だと
  画面端から8px浮いて、その隙間でホイールがページ送りになる／上端でメニューが出てしまう（上配置で発覚）。
- 左右配置の上端は、従来どおりメニューバー・ファイル名バー用に上端40px以上（出ていればその下）を空ける。
- 左右配置の**発火域**は、バーを置いた側の下角。**幅は固定100px、高さは画面高さの30%（最低100px）**（`thumbbar_corner_h`）。
  ページ送りゾーン（左右各100px幅）は、この角のぶんだけ下側がくり抜かれて無効になる（同じ値を参照するので発火域と保護域は常に一致）。
  左バーのとき、左のページ送りゾーンは「上端15%の下〜画面高さの70%」だけが有効になる。
- **上配置だけの特別仕様**（メニューバー・ファイル名バーの導線を残すため）:
  - バーは画面幅の左右を50pxずつ切り詰めて中央寄せ。この左右の遊びがメニューバー導線になる。
  - 何も出ていないときは、メニューバー・ファイル名バーを無視して上端（y=0）に置く。上端の中央部（左右100pxのページ送り保護域の内側）に入ると、バーが出る（メニューは出さない）。
  - バーが出ている間は、上端のホバーでもバーが優先でメニューバー・ファイル名バーは出ない。左右の遊び（x<50、x>w-50）の上端40pxにホバーするとメニューバー・ファイル名バーが出て、バーを押し下げる（メニュー高＋ファイル名バー32px。出ているぶんだけ）。メニュー（1秒後）・ファイル名バー（3秒後）が引っ込むたびに、Y位置は即時に再調整される。
  - メニューバー・ファイル名バーが先に出ているときは、バーの発火域も2つのバーより下の範囲になる（横は左右100pxの保護域を除く）。
  - 上配置でバーが隠れている間は、発火域（上端中央）がメニュー・ファイル名バーを新規に出さない範囲になる（バー優先）。
- **上以外の配置（下・左・右）でも、バーが出ている間は、上端中央のホバーでメニューバー・ファイル名バーを新規に出さない**（出せるのは左右の遊び＝左右それぞれ50pxの上端40pxからだけ）。バーが隠れている間は、メニューは通常どおり出る。

### サムネバーのスワイプとホイール

- マウスでバーをつかんで動かせる（スワイプ）。離した後は慣性で流れる（egui 標準の `DragScroll::Always`。既定はタッチ画面のみ）。
  一定以上動かすとドラッグ扱いになり、サムネのクリック（ジャンプ）は発火しない。つかみ中は握り手カーソル。
- スワイプ中（バー上で押したボタンが押されている間）は、ポインターがバー外へ出てもバーを消さない。離してから、バー外なら待機時間を数える。
- バー上のホイールは、バーの表示位置を動かす専用。ページ送り・ファイル送り（Shift＋ホイール）・虫眼鏡入場（拡大ホイール）へは渡さない（ページ送りはバーの外でのみ）。横配置（上・下）では縦ホイール（上下回転）を左右移動へ変換する（egui 既定では横向きの領域は縦ホイールに反応しないため、`always_scroll_the_only_direction` を有効にしている）。縦配置（左・右）は縦ホイールがそのまま上下移動。ホイールで動かした位置は、ページが変わるまで保たれる。
- パレットがバーに重なり、その上にポインターがある間は、バー側のスワイプ・ホイールを止める。

### サムネバー切替（ツールパレット）

- 新アクション `CycleThumbbar`（ID `cycle_thumbbar`）。カテゴリは「表示」。**既定のパレット割り当てには入れていない**
  （右クリックの登録メニューから各自のマスへ置く）。
- 押すたびに **OFF → 下 → 左 → 上 → 右 → OFF** と巡回する。`thumbbar_pos` を直接書き換え、永続化される
  （設定画面の「サムネバー配置」と同じ値）。
- マスの下側に現在状態を文字で表示する。表示中は緑、OFF は灰色。
  - 英語: TOP / BOTTOM / LEFT / RIGHT / OFF
  - 日本語: 上 / 下 / 左 / 右 / OFF
  - 中国語: 上 / 下 / 左 / 右 / 关闭
- 押した瞬間にその配置先へ実際に表示する。自動非表示で消えている最中でも、押下で操作時刻を更新するため再び見える。
  タイマーは押した時点から走る。
- 配置先が変わるとサムネバーのセンタリング記録を捨て、現在ページが中央に来るよう再スクロールする。

### ツールパレットとの前後関係（オーバーレイ統一）

- サムネバーはオーバーレイ方式のみ（旧「重ねて表示」設定は廃止。保存キー `thumbbar_overlap` は読み捨て）。
  バーはパレットより先に描くので、ツールボックスが前面になる。
- パレットが実際に描かれている矩形の上では、サムネのクリック・ホバー強調・バーのスワイプ／ホイールを受け付けない（イベントを貫通させない）。
- パレットの自動ハイドで無描画になっている間は、バー側が通常どおり反応する。

## 手動テスト

1. 30ページ程度のアーカイブを単ページで開く。サムネバー（設定で配置を選ぶ）の20枚目をクリック → 20ページ目が表示される
2. 同じアーカイブを見開き（左・右とも）にして、サムネの任意ページをクリック → そのページを含む見開きになる
3. 見開きで offset を +1P にしてから 1 ページ目のサムネをクリック → 先頭が仮想左付きの見開き（offset は -1 表示）になる
4. サムネバーをマウスでドラッグしてスクロール → ジャンプしない／ドラッグを離した位置でも誤ジャンプしない
5. 左上ホバーでエントリリストを出し、行をクリック → そのページへジャンプ。見開きでは含む見開き
6. ツールパレットの登録メニューから「サムネバー切替」を置く。ボタンを5回押す → OFF→下→左→上→右→OFF、各状態の文字が正しい
7. OFF の状態で押す → 即座に下にサムネバーが出る
8. 自動非表示（設定の待機時間を短く）で消えた後に押す → 再び出て、そこから待機時間が数え直される
9. 配置を変えて再起動 → 最後の状態が維持されている
10. パレットをサムネバーに重ねる（ツールボックスが前面に見える） → 重なり部分のクリックはパレットのボタンが受け、サムネはジャンプしない／バーもスクロールしない
11. 言語を英語・中国語に切り替え、マスの状態文字（TOP/BOTTOM/LEFT/RIGHT/OFF、上下左右/关闭）を確認
12. サムネバーをマウスでつかんで横（縦）に動かす → バーが追従し、離すと慣性で流れる。動かした後に離してもジャンプしない
13. スワイプ中にポインターをバーの外へ出す → バーは消えない。離すと、バー外なら待機時間の後に消える
14. 下（上）配置でバー上のホイールを回す → バーが左右に動く（ページは動かない）。左（右）配置では上下に動く。バーの外でホイールを回すと従来どおりページ送り
15. 左上ホバーでエントリリストを出す（メニューバー・タイトルバーが出ている状態も含む）→ 一覧の上端がメニュー＋タイトルバーの下から始まり、重ならない
16. エントリリスト上でホイールを回す → リストだけがスクロールし、ページは動かない。リストの外ではページ送り
17. リストをホイールで遠くまでスクロールしてから、行をクリック → ページが移り、リストがクリックした行へ滑らかにスクロールして着地（先頭・末尾付近は中央まで行かない）
18. リストをホイールでスクロールしたあと、いったんリストを隠してから出し直す → 現在ページが中央（先頭・末尾付近は端寄せ）の初期位置に戻っている
19. エントリリストを出す → 本画像が縮まず・ずれない（リストが画像の前面に半透明で重なる）。背景が50%透過で、背後の画像が透けて見える
20. リストにツールボックスを重ねる → ツールボックスが前面。重なり部分のクリック・ホイールはパレットが受ける
21. エントリリストの行の文字に影が付き、明るい画像の上でも読める。選択中の行・ホバー行の強調背景が出る
22. リストをマウスでつかんで上下に動かす → リストが追従し、離すと慣性で流れる。動かした後に離しても行のクリック（ジャンプ）は発火しない
23. スワイプ中にポインターをリストの外（右）へ出す → リストは隠れない。離すと、リスト外なら隠れる
24. 左（右・下）配置のバーが画面端にぴったり寄っている（隙間なし）。バーの端でホイールを回しても、ページは動かずバーだけが動く
25. 上配置: 何も出ていない状態でポインターを上端中央へ → バーが上端に出て、メニューバーは出ない。バー幅は左右50pxずつ空いている
26. 上配置でバーが出ているとき、左右の遊びの上端（40px）へホバー → メニューバー・ファイル名バーが出て、バーが押し下げられる。メニューが引っ込むと上へ戻り、ファイル名バーが引っ込むとさらに上端へ戻る
27. 上配置: メニューバー・ファイル名バーが先に出ているとき → バーはその下の検知域（上端ではない）で出る
28. 下（左・右）配置でバーが出ているとき、上端中央までポインターを動かしてもメニューバー・ファイル名バーは出ない。左右の端（x<50、x>w-50）の上端からは出る。バーが隠れている間は、上端へ行けば通常どおりメニューが出る
29. 左（右）配置で、画面の下側3割（幅100px）にポインターを入れるとバーが出る。ウィンドウの高さを変えても、下側3割に追従する。その範囲ではページ送り（◀▶）の反応が出ない
