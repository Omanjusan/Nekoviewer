# アーカイブの詳細テキスト・ページ数・TXTページ

リスト表示に「ページ数」「詳細」の2列を足し、zip/cbz内のTXTを画像ページとして開けるようにした。
カード表示は変えていない（UIが一杯のため）。

## 1. ページ数列と記録

- 値は**ビューアーでアーカイブを開いた時点**で記録する（`open_progress.rs` の `record_archive_meta`）。開くまでは空欄。
- 記録先は、サムネと同じフォルダ別 `cache.redb` の `archive_meta_v1`（[neko_dir.rs](../../src/neko_dir.rs)）。
  キーはファイル名、値は (mtime, size, ページ数, 詳細フラグ)。再計算できるキャッシュで、`file_settings_v2` とは分けてある。
  - mtime・sizeが現物と違う行は無効として扱い、列に出さない（`ArchiveMetaRow::is_current`）。
  - ビューアーを開いたファイル自身のフォルダへ書く（仮想フォルダ・お気に入り・検索から開いても同じ）。書けなくてもオープンは止めない。
- 全形式（zip/7z/tar/フォルダ）で記録する。ページ数は画像の数。TXTページは既定で数えない（§4の設定で含められる）。
- 表示は数値、999を超えたら `>999`、未取得は空欄（`meta::format_page_count`）。
- 列の読み込みはフォルダ単位のメモリキャッシュ（[archive_info_cache.rs](../../src/view_explorer/archive_info_cache.rs)）。
  フォルダを開き直すか、ビューアーを開くたびに、そのフォルダの分を読み直す。

### ソート

- 「ページ数」見出しのクリックと、ソートメニューの `[ページ数]` で並べ替える。**評価系の第2セット**（スコア・訪問回数と同じ）に `Pages` を足した。
  降順 → 昇順 → OFF の順に切り替わる。
- 未取得は0として扱う。昇順にすると未取得が先頭に集まる（回収しやすい）。同順位は第1セットの条件で並ぶ。
- state の `rating_sort_key` に `pages` が入る。旧版は未知の値として OFF 扱いになる。

### 列幅

- state の `explorer_list_cols` は7値（重複・名前・サイズ・更新日時・評価・訪問回数・ページ数）。旧版の6値も読め、ページ数だけ既定幅になる。
- 「詳細」「エラー」「属性」は固定幅で、`explorer_list_cols` に含めない。

## 2. 詳細列と詳細ウィンドウ

- 詳細テキスト（ComicInfo・付属テキスト・zipコメント）があるzip/cbzの行に、ファイラー列と同じ書類アイコンを出す（ビューアーを開いたときに有無を記録）。ソートなし。
- アイコンを押すと詳細ウィンドウが開く（[detail_window.rs](../../src/view_explorer/detail_window.rs)）。行の選択やビューアー起動はしない。
  - ウィンドウは1つだけ。別ファイルのアイコンを押すと中身が差し替わる。
  - 読み出しは別スレッド。読み込み中は「読み込み中…」。読めない・詳細なしなら、その旨を出す。
  - 本文は選択・コピーできるが、リンクにはならない（ComicInfo の Web 欄も文字のまま）。1つの本文は2万文字で切る。
- 詳細の出どころ（[meta.rs](../../src/fs/archive/meta.rs)、zip/cbzのみ）:
  - ComicInfo.xml（タイトル・シリーズ・話数・巻・著者・作画・出版社・レーベル・ジャンル・タグ・年・月・言語・ページ数(記載値)・Web・あらすじ）。
  - 内部の付属テキスト（最大4件）: `*.nfo`、およびファイル名が `info.txt` / `readme.txt` のもの（大文字小文字は区別せず、サブフォルダ内も可。完全一致のみ）。
    **info.txt / readme.txt は、詳細として拾ったうえで、TXTページ（§3）としても残る**（同じ内容が2か所に出る）。ほかの `.txt` は詳細にならず、TXTページとしてだけ扱う。
  - zipコメント。

### 安全方針

- 読み出しは1件256KBで `take`。宣言サイズは信用しない（zip爆弾対策）。ディスクへは展開しない。
- 表示前に制御文字・BiDi制御・BOM・ゼロ幅スペースを除き、結合文字は連続3つまでにする（`sanitize_text`）。
- 文字コードは BOM → UTF-8 → Shift-JIS → GBK → EUC-KR → Windows-1252 の順（`decode_text_bytes`）。
- XMLパーサは使わない。必要なタグの中身だけを取り出し、実体は基本5種と数値参照だけ解く。独自実体は展開しない。
- 暗号化・壊れたエントリは黙って飛ばす。

## 3. TXTページ（zip/cbzのみ）

アーカイブ内の `.txt` を、白地に黒文字の画像1ページとして扱う（[text_page.rs](../../src/fs/archive/text_page.rs)）。

- 読み出し側（zip の `load_bytes_from_archive`）が、本文を読み込み上限まで読み、目印（`NEKOTXT1`）・ページ・高さ上限・フラグを付けた
  ペイロードに包んで返す。`decode_image_bytes` が目印を見て文字を描く。キャッシュ・サムネ・メモリ見積もりはふつうの画像と同じ経路。
- 組版は**等幅グリッド**（全角=2マス、半角=1マス、結合文字=0マス）。幅1200px、文字約30px、行高45px、余白48px。横書きのみ。
  ページ数が本文だけから決まるので、分割モードでも一覧取得時に正確なページ数が出る。
- フォントは既存のシステム日本語フォント（簡体字フォントがあれば後段）と egui 標準フォント。字形は日本語寄りになる。
  どのフォントにも無い文字は □（それも無ければ空白）。
- 高さ上限を超えたとき:
  - **切り詰め**（既定）: 上限の行数で切り、最終行を「…」にする。1エントリ。
  - **ページ分割**: 複数ページにする。2ページ目以降は表示名が `a_p02.txt` 形式。仮想エントリ名は `<名前>\u{1f}<ページ番号>`。最大500ページ。
- 読み込み上限を超えて切れた場合は、末尾に「…」の行を足す。組版する文字数は60万字まで。
- TXTだけでアーカイブが成り立つ（画像0枚でも開ける）。サムネは1ページ目。
- 7z/tar/フォルダ内のTXTは未対応（読み出し経路が別）。

## 4. 設定

設定ダイアログの共通タブに「TXT」の節。state の `app_text_page`（`有効,高さ,分割,読込KB,算入` の1行）に保存し、変更は次に開くアーカイブから効く。

| 項目 | 既定 | 範囲 |
|---|---|---|
| TXTを画像ページとして開く | ON | — |
| 高さ上限 | 4000px | 600〜8192 |
| 超えたとき | 切り詰め | 切り詰め / ページ分割 |
| 読み込み上限 | 1MB | 64KB〜4MB |
| リストのページ数にTXTを含める | OFF | — |

## 未対応・注意

- 7z/tar/フォルダ内のTXT。
- 縦書き・禁則処理・合字・RTL・アラビア文字などの結合形。ハングルやアラビア文字は、システムのフォントに無ければ □。
- 中国語TXTは日本語寄りの字形になる（判定した文字コードに応じて簡体字フォントを先頭にする改善の余地あり）。
- 分割モードは一覧取得時にTXTの本文を読む（上限まで）。TXTが多いアーカイブでは、開くまでの時間が延びる。
- ページ数・詳細有無は、ビューアーで開くまで空欄。開かないファイルは取得されない。
- 詳細テキストの抽出は zip/cbz のみ（7z/tar は未対応）。
- 記録は cache.redb（ファイル名キー）のため、ファイルの改名・移動では引き継がれず、開き直すと再記録される。

## 自動テスト

- `meta.rs`（抽出・安全化・文字コード・ComicInfo・zipの詳細）、`text_page.rs`（組版・ペイロード・描画・ページ分割・設定の文字列化）、
  `zip.rs` の `text_page_tests`（一覧・読み出し・分割・無効化・読み込み上限・TXTだけのサムネ）。
- `neko_dir.rs` の `archive_meta_tests`、`archive_info_cache.rs`、`explorer_sort.rs`（Pages のソート）、`list_columns.rs`（旧6値の互換）、
  `detail_window.rs`、`gui_config.rs`（`app_text_page` の読み書き）。
- 見本の画像出力: `NEKO_DUMP_DIR=<dir> cargo test dump_sample_pages -- --ignored`。

## 手動テスト手順

テスト用アーカイブは `test/detail_fixtures/` に置く想定（gitignore済み。生成スクリプトは手元で再作成可）。

### ページ数・詳細列
1. 開く前は、どのファイルも「ページ数」「詳細」が空欄。
2. `00_plain_no_detail.cbz` を開いて閉じると、ページ数が `5`、詳細アイコンなし。
3. `01_comicinfo.cbz`（ComicInfo）、`02_nfo_utf8_and_sjis.cbz`（nfo 2件）、`03_zip_comment.zip`（コメントのみ）、`04_all_detail.cbz`（3種）を開くと、詳細アイコンが付く。
4. `05_pages_999.cbz` は `999`、`05_pages_1000.cbz` と `05_pages_1200.cbz` は `>999`。
5. 7z・tar・フォルダを開くと、ページ数が入る（詳細アイコンは付かない）。
6. `11_empty_comicinfo.cbz`（中身が空のComicInfoと空白だけのnfo）は、詳細アイコンが付かない。
7. `10_broken_not_a_zip.zip` は開けず、無効アーカイブのトーストが出る。
8. ファイルを更新（touch など）してフォルダを開き直すと、そのファイルの値が空欄に戻る（記録が古いため）。開き直すと再記録される。
9. お気に入り・検索・仮想フォルダ経由で開いても、元のフォルダの一覧に反映される。
10. 「ページ数」見出しを押すと、降順 → 昇順（未取得が先頭）→ OFF。ソートメニューの `[ページ数]` でも同じ。再起動しても並びが残る。
11. 列幅をドラッグして再起動しても残る。旧版のstate（6値）でも起動できる。

### 詳細ウィンドウ
12. `01_comicinfo.cbz` のアイコンを押すと窓が開き、項目表が出る。タイトルの `&amp;` が `&` で出て、Web欄を押しても何も開かない。
13. `02_nfo_utf8_and_sjis.cbz` は付属テキストが2つ出て、UTF-8もShift-JISも文字化けしない。
    `12_info_txt.cbz` は詳細アイコンが付き、`info.txt` が「テキスト: info.txt」として出る（`other.txt` は出ない）。ビューアーでは `info.txt` も `other.txt` もTXTページとして開ける。
    `13_readme_txt_subdir.cbz` は、サブフォルダ内の `README.TXT` と、大文字小文字違いの `Info.Txt` の2つが出る。
14. `03_zip_comment.zip` はコメントだけ。`04_all_detail.cbz` は3区画とも出る。
15. `08_hostile_text.cbz` は、反転文字・制御文字・ゼロ幅・結合文字が除かれ、`&a;` はそのまま残る。nfo は `evil.nfo` と `escape.nfo` の2つ。ディスクにファイルが作られない。
16. `09_huge_nfo_and_txt.cbz` は、固まらず、長い本文に打ち切りの注記が出る。
17. 別ファイルのアイコンを押すと中身が入れ替わる。×で閉じられる。アイコンを押しても行の選択やビューアー起動は起きない。
18. 日本語・英語・中国語でラベルが切り替わる。

### TXTページ
19. `06_txt_pages.cbz` を開くと画像3枚のあとにTXTが5枚続く。UTF-8・Shift-JIS・UTF-16(BOM)・中国語が文字化けしない。リストのページ数は `3`。
20. `14_long.txt` が切り詰められ、最終行が「…」になる（高さ4000px）。
21. 設定で「ページ分割」にして開き直すと、`14_long` が `14_long_p02.txt` … と複数ページになる。ページ数は本文から決まった値になる。
22. `07_txt_only.zip`（TXTだけ）が開けて、サムネが出る。
23. `09_huge_nfo_and_txt.cbz` の `huge.txt`（約2MB）は、1MBで切れて末尾に「…」が出る。読み込み上限を256KBに下げると、さらに短くなる。
24. 設定で「TXTを画像ページとして開く」をOFFにして開き直すと、TXTは出ない。`07_txt_only.zip` は画像が無いので無効扱い。
25. 「リストのページ数にTXTページを含める」をONにして開き直すと、`06_txt_pages.cbz` のページ数が `8` になる。
26. 日本語・英語・中国語で設定の文言が切り替わる。設定を保存して再起動しても残る。
27. 見開き・コマモード・虫眼鏡・ページ送りが、TXTページでもふつうの画像と同じように動く。
