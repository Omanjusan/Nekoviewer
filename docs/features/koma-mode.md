# 疑似コマ送りモード

漫画のコマは人間的な枠組みなので論理的な解析はせず、ユーザーが決めた倍率のフレームで
ページ全体を読み順に塗りつぶすことを「コマ送り」とみなす機能。虫眼鏡（拡大表示）モードの上の
サブモード。ページ送りの完全な代替ではなく準互換の操作。

## 操作

- 入り方: 拡大表示中にツールボックスの`コマ送りモード`（`ToggleKind::KomaMode`）を押す。
  拡大表示外で押した場合は拡大表示にも入る。拡大表示が終わるとコマモードも終わる
  （毎フレーム `!magnifier_on` なら `koma_on=false`）。ON/OFFは非永続
- 基準倍率:
  - 拡大表示中に押した場合は、その時点の倍率が基準になる
  - 拡大表示外から入る場合は、保存済みの基準倍率（なければフィット）で先頭コマから始まる
  - モード中のホイール・スライダーでの拡縮は基準倍率を更新する
  - 保存キーは state の `magnifier_koma_height_rel`
- 進む/戻る: Space/↓/↑（ページ送りキー）と、ツールボックスのチップ`コマ送り`/`コマ戻し`
  （`ActionKind::KomaNext/KomaPrev`）。チップはコマモードOFFの間は何もしない。
  Shift+↑↓（ファイル送り系）・ホイール（拡縮）・左右端クリック（ページ送り）は従来どおり
- 最終コマでの「次」は通常のページ送りで、次ページの先頭コマへ。先頭コマでの「戻る」は前ページの
  最終コマへ。送れない端（最終ページの最終コマ・先頭ページの先頭コマ）では何も起きない

## コマの決め方（[koma.rs](../../src/koma.rs)）

- フレーム=ビューポート。各軸でコンテンツがフレームを超える分だけフレームを並べ、最後の1コマは
  ページ端へクランプする（前のコマと重なる）。フレームより小さい軸は1コマ（既存の中央寄せ）
- 並びはZ走査。行内は綴じ方向（右綴じ=右→左、左綴じ・単ページ=左→右）、行末で次行の先頭側へ戻る
- ドラッグ等で格子から外れた位置からは、最寄りのコマにスナップしてから前後へ進む
- 軸の超過が0.5px以下ならフレームに収まる扱い（微小な誤差の吸収のみ）。1軸のコマ数が1万を超える
  異常値は1コマに縮退する

## ページ跨ぎと倍率

- 基準倍率は「高さフィット相対」（1.0 = ページの高さがちょうど窓の高さに収まる倍率）で持つ
  （`height_rel_from_scale` / `scale_from_height_rel`）。見開きは幅でフィットが決まるが、ページ高さが
  同じなら同じ値になる。解像度が違うページ・見開き/単ページの切替・回転後も同じ式でフレームの大きさを保つ
- 新ページ（ビューの作り直し）は、この基準倍率から倍率を決めて先頭コマ（戻りなら最終コマ）へ置く
- ページ跨ぎの範囲丸め（最大倍率など）では基準倍率を更新しない。更新はユーザーの拡縮のみ
- 窓の高さが変わったら、高さ相対を保つよう倍率と位置を同じ比率で伸縮する

## アニメーション

- コマ間の移動は固定180ms（`koma::TWEEN_SECS`）。二次の加速のあと最後の25%だけ線形に減速して
  ピタッと止まる（`koma::tween_progress`。速度は連続、始点・終点とも0）
- アニメ中はコマ送り・チップ・ホイール拡縮・スライダー操作を完了まで無視する（キューには積まない）。
  ドラッグは毎フレームの位置の押し込みで実質上書きされる
- コマモードOFF・ビューの作り直し・倍率や窓寸法の変化で打ち切る。ページ跨ぎの到着は即時表示

## 構成

- 純ロジック: [koma.rs](../../src/koma.rs)（`KomaGrid`・`KomaMove`・`tween_progress`・高さ相対の換算）
- 状態: `ViewerConfig.koma_on`（非永続）、`MagnifierConfig.koma_height_rel`（永続。
  [magnifier.rs](../../src/magnifier.rs)）
- ナビ接続: [view_reader.rs](../../src/view_reader.rs) の `koma_step`（要求受付・境界判定）、
  `process_navigation`（キー）、`update_magnifier`（基準倍率の取り込み・新ページの開始位置・アニメ進行）
- ツールボックス: [tool_palette/toggle.rs](../../src/tool_palette/toggle.rs)、
  [tool_palette/action.rs](../../src/tool_palette/action.rs)

## 既知の課題

- 横方向のコマが、ほとんど動かないのに往復として重複して感じられることがある
  （微小な超過でもコマが増える。許容の扱いを検討中）
