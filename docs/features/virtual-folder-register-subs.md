# 仮想フォルダ: 実サブフォルダの一括登録

仮想フォルダのタブモードでは、実フォルダ側に新しく作ったサブフォルダは自動では現れない
（登録は登録時点のスナップショットのため）。この機能は、登録済みの仮想フォルダの実パスを
見に行き、まだ登録されていないサブフォルダだけを子として足す。

## 操作

仮想ツリーのフォルダを右クリック →「フォルダの実サブフォルダを一括登録」
（「実フォルダ登録」の直下）。確認ダイアログが開く。

- 表示: 対象の仮想パス、その実フォルダのパス、「登録済みのフォルダは変更されません」の注記
- チェックボックス「サブフォルダの子（孫以降）も登録する」（初期値 OFF）
  - OFF: メニューを出したフォルダの直下のサブフォルダだけを見る
  - ON: 子孫すべてを見る。登録済みの子の配下にある未登録フォルダも補完する
- 完了トースト: 「実サブフォルダを n 件登録しました」。0 件なら「登録するサブフォルダはありませんでした」

メニューはルート（`/`）とリンク切れ（実パスをフォルダとして開けない）ノードではグレーで押せない
（「実ツリーと同期」と同じ条件）。

## 動作の規則

- 追加のみ。登録済みのノード（実パスで照合）は残し、実フォルダが消えたノードにも触らない
- 追加したノードは、同じ親の兄弟の末尾に並ぶ
- 隠しフォルダ（`.` 始まり）も含める（実フォルダ登録と同じ）。シンボリックリンクのフォルダは除外
- 評価・スキャンは別スレッドで行い、UI を止めない。ネットワークマウント配下で到達不可なら中止する
- 1回の登録は1件ずつ。登録中・大量取り込みの選択待ちの間に押しても無視される

## 大量時

追加予定が 1000 件を超える、またはスキャンが打ち切り上限に達したときは、既存の
大量取り込みダイアログ（全部／浅く／キャンセル）に合流する。件数は「追加される分」で数える。

- 全部: 打ち切りのとき、または残り容量（`MAX_NODES`）を超えるときは選べない
- 浅く: 追加件数が閾値と残り容量の小さいほうに収まる最も深い階層まで。追加 0 件の階層は選べない

## 実装メモ

| 場所 | 内容 |
|---|---|
| `virtual_folders::merge_snapshot` | 追加のみの差分反映（DB書き込み。上限超過なら何も追加しない） |
| `virtual_folders::merge_depth_counts` | 追加される件数を深さ別に数える（大量判定・「浅く」の材料） |
| `virtual_folder_scan::scan_subtree_limited` | 深さ制限つきスキャン（OFF のとき `Some(1)`）。制限で止めても `capped` にしない |
| `view_explorer/virtual_ui/register.rs` | `RegisterKind::{New, Merge}`、`start_merge_subfolders`、確認ダイアログ、トースト |

`RegisterKind::Merge` のとき、`dest` は「登録先」ではなく「実サブフォルダを足す対象ノードのid」を指す。
