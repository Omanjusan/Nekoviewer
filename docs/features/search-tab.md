# 検索タブ（新モード／旧モード）

ファイルを探して、フォルダをまたぐフラットな一覧（カード／リスト）に出すタブ。左ペインの「検索」。
**新**（既定）はファイルIDの台帳の全件が対象で、**旧（フォルダ指定）**は基点フォルダ配下のサムネDBを探す従来の検索。

条件の履歴の保存と復元は [search-history.md](search-history.md)、タグから探す別のタブは [tag-search.md](tag-search.md)、
自動テストの実行方法は [../e2e-search.md](../e2e-search.md)。

実装: [ledger_search.rs](../../src/ledger_search.rs)（新モードの走査エンジンと検索ジョブ）、
[search_new.rs](../../src/view_explorer/search_new.rs)（新モードの実行の配線）、
[search_ui.rs](../../src/view_explorer/search_ui.rs)（フォーム・履歴の描画）、
[search.rs](../../src/view_explorer/search.rs)（旧モード・履歴・結果の表示）、
[search_history_ui.rs](../../src/view_explorer/search_history_ui.rs)（履歴の上限・空条件の判定・復元）、
[goto_virtual.rs](../../src/view_explorer/goto_virtual.rs)（仮想フォルダ列の移動）、
[similar_search.rs](../../src/similar_search.rs)・[similar_cross.rs](../../src/view_explorer/similar_cross.rs)（「？」の照合）。

## 画面

- 左ペインの上から、モード切替 `[新｜旧（フォルダ指定）]`、条件フォーム、区切り線、**「検索開始」「条件クリア」**、検索結果の履歴。
  ボタンは新旧共通で、条件フォームの**直下**にある（フォームの高さに合わせて上下に動く。フォームが高すぎるときだけ、フォームがスクロールになる）。
- 新旧の入力欄は**独立**で、切り替えても互いの入力は消えない。「条件クリア」は、いまのモードの欄だけを空にする。
- 履歴の一覧は、**いまのモードの行だけ**を出す（新では新の履歴、旧では旧の履歴）。モードを切り替えると、表示中の結果をクリアして、
  切り替え先のモードの行で描き直す。
- 中央は、結果を選ぶまで案内の文字だけ。検索を始めると、その結果が自動で選ばれて出る。
- 結果の一覧は、カード／リストの両方で見られる（カードは従来どおり。リストの列は下の「リストの列」）。

## 新モード

- **対象**: ファイルID（spread DB）の台帳の全件。フォルダのサムネDBの有無やサムネ生成の有無は関係ない。
  ただし、台帳に載るのは、一度でもフォルダを一覧表示した（または記録が書かれた）ファイルだけ。一度も開いていないフォルダのファイルは対象外。
- **条件欄**: 「検索文字列（ファイル名・タグ名）」と「サイズ以上／以下（MB）」。日付は無い（後から足せる作り）。
- **検索文字列**（フォームの欄にホバーで説明が出る）:
  - 半角・全角のスペースで単語を区切る。スペースを含む語は `"サン　プル"` のように `"` で囲む（全角の `“ ”` も可）。
  - **どれか1つの語に当たればヒット（OR）**。当たる先は、ファイル名と、ファイルに付いているタグの名前（全カテゴリの全要素。別名 `A|B|C` のどれでも）。
  - 照合は大文字小文字を区別しない部分一致。ファイル名は従来どおり `* ? [` を含む語を glob として扱う。
  - サイズとは AND。
- **空の条件は始められない**（新旧とも。[search-history.md](search-history.md)）。文字列かサイズのどちらかが有効に入っている必要がある。
  押せないときは、「検索開始」にホバーで理由が出る。
- 前回の確認でファイルが見つからなかったレコード（オフライン等）は、一覧から外し、履歴の行ラベルに「確認不可N件」を添える。
- 実行は**アプリ本体が持つバックグラウンドジョブ**。専用スレッドが台帳を走査し、ヒットを200件ずつ送る。
  - 実行中は履歴の先頭に行ができ、結果が溜まっていく。ラベルに進捗「n/N」（調べた件数／台帳の総数）が出る。
  - 「検索開始」は、実行中は「**中断**」に変わる。押すとそこまでの結果を残して打ち切る（ラベルに「中断」が付く）。
  - 検索は**同時に1つだけ**（旧・新を通して）。実行中は開始できない。
  - **他のタブへ移っても、走査と収集は続く**。結果は履歴の行へ溜まり、その間、他のタブの一覧には触れない。
    検索タブへ戻って行を選ぶと、集まった結果が出て、続きも追記される。
- 結果の一覧に出すとき、表示中の行だけがサムネなどを要求する（遅延）。件数が多くても重くならない。
- 「新検索モードの注意点」ボタン（フォームの最後）で、ダイアログ（右上の×だけで閉じる）が開く。内容は、次の「マーカー」のとおり。
  マーカーの注意に加えて、「全データベースを走査する（効くのはファイルID）」「フォルダを巡回してDBを完成させる」「上部のサムネイル数の横のID取得状況を参考にする」旨も載せている。
- **消えたファイルの除外（表示中のみ。検索結果とタグ検索の結果の両方）**: 台帳には、消した後まだそのフォルダを巡回していない行が「確認済」のまま残る。
  サムネ取得で「元ファイルの更新時刻を読めない」（`ThumbResult.missing`。キャッシュ済みサムネを返した場合も立つ）と分かったものは、
  赤Xを付けずに表示中の一覧から外す（`drop_missing_from_search_view`）。履歴（`entry.hits`）とDBは変えない（ファイルが戻れば、開き直すと再び出る）。
  **ネットワークマウント配下は外さない**（接続不調でstatに失敗しただけの可能性があるため。従来どおり赤Xになる）。
  遅延除外なので、サムネが要求された（見えた）ものから順に外れる。
- 検索タブ・検索結果の表示中（お気に入り・タグ検索・類似も同様）は、メニューバーの「サムネイル n/m（ID…）」ラベルを出さない（実フォルダ向けの表示のため）。

## マーカー（新モードの結果のみ・読み取り専用）

- 結果に、**保存済みの**重複マーカーと、保存済みハッシュによる「？」（サムネが似ている）を、読み取り専用で出す。
  詳細は [duplicate-marker.md](duplicate-marker.md)・[similar-image-marker.md](similar-image-marker.md) の「検索結果での表示」。
- クリックしても何も起きない（類似ファイル一覧へは飛べない）。ホバー説明の末尾に「検索結果からは一致・類似ファイルリストには飛べません。」が出る。
- 解決は、リストの「実」「仮想」の移動アイコンで現地のフォルダへ移ってから行う。

## 旧モード

- 従来の検索。基点フォルダ（左のツリー／ドライブで選ぶ）の配下の、サムネDB（cache.redb）の索引だけを探す。サムネを作っていないフォルダはヒットしない。
- 条件欄は「検索基底フォルダ・ファイル名・サブディレクトリを含む・サイズ・日付」。ファイル名は単一のパターン（`* ? [` の glob、無ければ小文字の部分一致）。
- 新モードを選んでいる間は、アイテムペインのツリー／ドライブを隠す（基点フォルダを使わないため）。旧に切り替えると出る。
- 旧モードへ入るのは、検索タブの「新／旧」の切り替えから。右クリックの「このフォルダを検索タブで開く」は廃止した（新モードを主にするため）。ファイルの右クリック「主要タグ検索」は新モードで実行する（[main-tag-search.md](main-tag-search.md)）。
- 空の条件（ファイル名・サイズ・日付が全部空）では始められない。基点フォルダだけでは足りない。
- 結果は完了時に履歴へ入る（途中経過は出ない）。進捗表示・中断は無い。マーカーは出さない。

## リストの列（横断一覧）

検索結果・お気に入り・タグ検索・類似ファイル一覧のリスト表示には、通常のフォルダ表示に無い列が出る（[explorer-view-modes.md](explorer-view-modes.md)）。
- **場所**: 親フォルダのフルパス（長いときは先頭を省略、ホバーで全文）。
- **実／仮想**（ファイラー列の右、丸の中の→矢印。実=青〜水色、仮想=緑。幅はドラッグで変えられる。カードには出ない）:
  - 「実」を押すと、そのファイルの親フォルダを**フォルダタブ**で開き、ファイルを選択して見える位置へスクロールする。
    届かない場所はトーストで知らせて、何も変えない。
  - 「仮想」を押すと、その親フォルダを登録している仮想ノードを逆引きして、**仮想フォルダタブ**でそのノードを開き、同じくファイルを選ぶ。
    登録が1つならそこへ、複数なら仮想ツリーでのパスを並べた選択メニューが出る（外側の押下か Esc で閉じる）。
    登録が無いときは灰色で、押しても何も起きない。逆引きは、タブを移るたびに DB から引き直す。
- どちらも、選択や起動はしない。移動の要求は、一覧の描画が終わってから消化する。

## タブを移ったときの扱い

- 検索タブを離れる直前に見ていた結果は、検索タブへ戻ると**そのまま出し直される**（結果を持つ行のみ）。
  モードを切り替えてクリアしたとき、結果を手放した行、別のモードへ変わっていたときは、出し直さない。
- 他のタブへ移った直後は、実フォルダのスキャンが結果を受け取らないまま保留になる。このとき、検索タブなどに「読み込み中」を出し続けない
  （結果を受け取る表示でだけ出す）。フォルダタブへ戻ると、保留されていた結果が届いて一覧が出る。

## 手動テスト手順

画面の見た目とマウス操作は自動テストで確かめていない。フォルダを2つ以上用意し（同名のファイル、似た画像、同じ内容のコピーを含める）、
それぞれを一度ずつ開いてから試す。履歴の保存・復元の項目は [search-history.md](search-history.md) に別にある。
