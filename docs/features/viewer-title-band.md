# ビューアーの仮想タイトル帯とメニューバー自動ハイド

OSのタイトルバーは固定の `Nekoviewer - Imageview` のまま変えない（Wayland/GNOME のCSDが CJK を描けず豆腐になるため。
[view_reader.rs](../../src/view_reader.rs) の該当コメント参照）。ファイル名は egui 内の「仮想タイトル帯」で出す。
ウィンドウモードのメニューバーは、自動ハイドで普段は引っ込められる。どちらも `view_reader.rs` の実装。

## 仮想タイトル帯（`tick_title_band` / `draw_title_band`）

- 画像の上に重ねる半透明の黒帯（高さ32px、Foreground層）。ファイル名のみ（`Nekoviewer - ` のプレフィックスなし）を帯の上下左右中央に1行。
  入力は握らない。長い名前は省略せず、帯の幅で切れる（未対応）。
- **開いた直後に3秒**表示。**ウィンドウ上端40px**にポインタが来ると表示。ホバーが外れて**3秒待って**隠す。
  待機中も帯の範囲にポインタがあれば保持。
- フルスクリーンでも同じ判定（ウィンドウ上端 = モニタ上端）。フルスクリーンのソートバーとは独立で、
  上端が重なる場合の整理は未定。
- メニューバーの自動ハイドの設定には依存しない。ただし自動ハイドのバーが見えている間は、巻き込みで帯も出し続け、
  バーが引っ込んだ時点から通常の3秒待機に入る。バーの直下に縦積みで出る。

## メニューバー自動ハイド（ウィンドウモード専属）

- バー最右端（`[ウィンドウ位置]` の右）の `[自動で隠す]` ボタンで切り替え。既定OFF、永続
  （state の `menubar_autohide`、`ViewerConfig.menubar_autohide`）。
- **OFF**: 従来どおり、画像エリアを削る常時表示のパネル。
- **ON**: 画像の上に重ねるオーバーレイ（`draw_overlay_menubar`）。画像は動かず再フィットもしない。
  上端40pxで出現、ポインタがバー高+10pxの範囲から外れて**約1秒**で引っ込む（`MENUBAR_HIDE_WAIT_SEC`）。
  - 「ウィンドウ位置」メニュー等のポップアップや、上書き確認ダイアログの表示中は引っ込めない。
  - 引っ込んでいる間はトグルも見えない。上端にポインタを寄せて出してから押す。
- **フルスクリーンには一切影響しない**。フルスクリーン時は従来の専用ソートバー（上端ホバー式）のまま、
  この設定を見ない。

## 定数（仮置き・調整可）

| 定数 | 値 | 場所 |
|---|---|---|
| `MENUBAR_HIDE_WAIT_SEC` | 1.0 | view_reader.rs 冒頭 |
| `TITLE_BAND_HIDE_WAIT_SEC` | 3.0 | view_reader.rs 冒頭 |
| 開いた直後の表示秒数 `OPEN_SHOW_SEC` | 3.0 | `tick_title_band` 内 |
| 上端トリガー高 `TRIGGER_H` | 40px | `tick_title_band` / `draw_overlay_menubar` 内 |

## 未対応・注意

- 長いファイル名の省略表示。
- フルスクリーンでソートバーとタイトル帯が上端で重なる場合の整理。
- 上端のリサイズ枠・OSタイトルバーへ向かう動きと、上端40pxトリガーの誤爆（特にWayland CSD）。
- 自動テストは設定の保存/復元（`menubar_autohide_parses_and_defaults_to_off`）のみ。表示挙動は下記の手動確認。

## 手動確認

1. 既定（state無し）でメニューバーが常時表示される。右端に `[自動で隠す]` がある（`[ウィンドウ位置]` の右）。
2. `[自動で隠す]` をONにするとバーが引っ込み、画像が上端まで広がる。再起動してもONのまま。
3. ON中、ウィンドウ上端にポインタを寄せるとバーが画像の上に重なって出る。画像は動かない。
4. バーからポインタを外すと約1秒で引っ込む。
5. `[ウィンドウ位置]` メニューを開いている間は、ポインタを外してもバーが残る。閉じると約1秒後に引っ込む。
6. 上書き確認ダイアログの表示中もバーが残る。
7. バーが出ている間、直下にタイトル帯が縦積みで出る。バーが引っ込んだ約3秒後に帯も消える。
8. OFFに戻すと、従来の常時表示パネルに戻り、画像エリアが削られる。
9. ファイルを開いた直後、タイトル帯が約3秒出て消える（自動ハイドOFFのときも）。
10. 上端にポインタを寄せるとタイトル帯が出て、外して約3秒後に消える。日本語・英字・絵文字のファイル名が豆腐にならない。
11. フルスクリーンにすると、自動ハイドの設定にかかわらず従来のソートバー（上端ホバー式）のまま。トグルは出ない。
12. 日本語・英語・中国語でボタン名とツールチップが切り替わる。
