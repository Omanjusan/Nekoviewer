# ソート展開メニュー（エクスプローラー）

エクスプローラーのメニューバーにあったソート関連の7ボタンを、展開メニュー1個に集約した。
メニューは3ブロックで、末尾の「ビューアーのデフォルト（任意）」で、ビューアーで保存済みソートの無いファイルを
開くときの初期条件を決める。ビューアー側のツールバー（名前・自然数・日付・昇降のボタン）は従来のまま。
実装は [panels.rs](../../src/view_explorer/panels.rs)（`draw_sort_menu` / `sort_menu_items` / `apply_sort_menu_item` /
`handle_sort_menu_keys`）、メニューバーのキー操作は [input.rs](../../src/view_explorer/input.rs)
（`handle_menu_bar_keys`）、ボタン部品は [view_reader.rs](../../src/view_reader.rs)（`sort_choice_button` / `sort_order_button`）。

## 見た目

メニューバーのボタン表示は `ソート: 名前 昇順`。評価キーがONなら優先順に `ソート: スコア 降順 > 名前 昇順`。
`MenuBarButton::Sort` の1個で、`MENU_BAR_ORDER` は17→11項目。

```
＜基本キー＞ [↑ 昇順]
 名前  日付  サイズ
-----------------
＜評価キー（任意）＞ [↓ 降順]
 スコア  訪問回数
評価キーがONのときは評価キーが優先され、同順位を基本キーで並べる。任意キーの条件は選択中のボタンをもう一度押すと無効化可能。
-----------------
＜ビューアーのデフォルト（任意）＞ [↑ 昇順]
 名前  自然数  日付
デフォルトキーが設定されていても、ソート条件を保存したファイルは保存された条件が優先されます。
```

- 選択肢（キー）は薄いグレー背景＋枠のボタン。選択中は塗り色＋白文字（基本キー＝青、評価キー＝赤、ビューアーのデフォルト＝緑）。
- 昇順/降順は塗りなし＋青系の枠線＋矢印（`↑ 昇順` / `↓ 降順`）。キー選択と同列に見えないようにするため。
  矢印は [glyph_audit.rs](../../src/view_explorer/glyph_audit.rs) で豆腐チェックする。
- キー名は括弧なしの文字だけ（i18n 定義は `[名前]` 形式のまま、表示側で括弧を外す）。
- 基本キー・評価キーの見出しにポインタを乗せる（ヘルプON時）と、従来のヘルプ文が出る。

## 基本キーと評価キー

- 並びの意味は従来から変えていない（[archive-rating.md](archive-rating.md)「評価順・訪問回数順のソート」）。
  評価キーがONの間は評価キーが主軸、同順位を基本キー。名称だけ「第1/第2セット」から「基本キー」「評価キー（任意）」に改めた。
- 評価キーは選択中のボタンをもう一度押すとOFF。OFFの間は評価キーの昇降ボタンがグレーアウトする。
- 状態はエクスプローラー側のデフォルトという概念を持たず、最後に使った条件を次回起動で復元する従来のまま
  （state の `sort_key` / `rating_sort_key` ほか）。リスト表示の列見出しソートとも状態を共有する。

## ビューアーのデフォルト（任意）

- 対象は、**保存済みソート条件（[archive-sort-state.md](archive-sort-state.md)）が無いアーカイブをビューアーで開くとき**の初期条件。
  優先順位は **ファイル単位の保存済み条件 ＞ このデフォルト ＞ 名前・昇順**。単一画像（raw）は対象外。
- 適用は `open_viewer`（[viewer_host.rs](../../src/view_explorer/viewer_host.rs)）。このとき保存はONにならない
  （「現在のソート条件を保存する」はOFFのまま）。
- キー（名前・自然数・日付）は**トグル型・排他**。選択中のキーをもう一度押すと「指定なし」になり、従来どおり名前・昇順で開く。
  既定は指定なし。昇降ボタンは、キーが未指定の間はグレーアウトする（向きの値自体は覚えておく）。
- 変更しても、いま開いているビューアーの並びと、エクスプローラーの並びは変わらない（次に開くファイルから効く）。
- 保存先は state の `viewer_default_sort_key`（`off`/`name`/`natural`/`date`）と `viewer_default_sort_ascending`
  （`ViewerConfig.default_sort_key: Option<ReaderSortKey>` / `default_sort_ascending`）。未知値・欠落は「指定なし」、
  向きが壊れていれば昇順。メニューを操作した時点で保存する。

## キーボード操作（メニューバー）

- バー側のカーソル（左右キー）が「ソート」に**着いた時点で自動展開**し、カーソルを最上位（基本キーの昇降）に置く。
  別のボタンへ移ると縮小する。Tab でペインを移る／Esc／メニュー外クリックでも閉じる。
- メニューが閉じている状態で、カーソルがソートにあるとき **↓** で展開し最上位へ。Enter でも開閉できる。
- メニュー内は **↑↓ だけ**で、全ボタンを1列として移動する。順序:
  基本キーの昇降 → 名前 → 日付 → サイズ → 評価キーの昇降 → スコア → 訪問回数 → ビューアーのデフォルトの昇降 → 名前 → 自然数 → 日付。
  - 評価キーの昇降は評価キーがOFFの間、ビューアーのデフォルトの昇降はキー未指定の間、押せないため飛ばす。
  - 先頭で ↑ を押すとメニューを閉じる（バー側カーソルはソートに残る）。
  - 末尾（ビューアーのデフォルトの「日付」）で ↓ を押しても何も起きない。上下で隣のメニュー項目へは移らない。
- **←→** はメニュー内の選択には使わない。押すとメニューを閉じ、バー側カーソルがその方向の隣へ動く。
- Enter でカーソル位置の項目を実行（クリックと同じ処理 `apply_sort_menu_item`）。評価キーのON/OFFなどで昇降ボタンの
  有無が変わるため、実行後は同じ項目にカーソルを追従させる。
- マウスで開いた場合はメニュー内カーソルを出さない。その状態でソートボタン上で ↓ を押すとカーソル付きになる。

## 自動テスト

- ビューアーのデフォルトの保存/復元・フォールバック: `viewer_default_sort_round_trips_and_falls_back`（gui_config.rs）。
- メニューバー順序: `menu_bar_order_tests`（view_explorer/mod.rs）。
- 昇降矢印の豆腐チェック: `sort_order_arrow_glyphs_are_available`（glyph_audit.rs）。
- メニューの描画・キー操作・デフォルト適用は自動テストなし。下記の手動確認。
