# 主要タグ検索（右クリックのワンアクション検索）と右クリックメニューのテーマ分け

エクスプローラーのファイル（カード・リストの行）を右クリックして、そのファイルの**主要タグ**（グループ・作者・演者・キャラクター・パロディ元・イベント・言語・年月）で、ワンアクションで検索する。
あわせて、エクスプローラー側の右クリックメニューを、テーマ見出し（太字・クリック不可）とインデントした項目に整理した。

実装: [search_keys.rs](../../src/search_keys.rs)（名前の解決・取得状況の判定・検索文字列。画面に触れない純関数）、
[key_search_ui.rs](../../src/view_explorer/key_search_ui.rs)（メニュー・選択ダイアログ・案内ダイアログ・検索の起動）、
[ui_widgets.rs](../../src/ui_widgets.rs)（`menu_theme_heading`・`menu_theme_items`）。

「主要タグ」は、タグ管理のうち決まった種類のカテゴリ（グループ・作者など）を指す。ユーザーが作った独自のタグは対象外。形式（zip等）・メイン・属性タグも対象外。

## 主要タグ検索（カードの右クリック）

右クリックメニューの見出し「検索」の下に「主要タグ検索 ▶」がある。サブメニューは次の並び。

```
グループ
作者
演者
キャラクター
パロディ元
イベント
言語
年月
───────
主要タグ取得状況: …
```

- 種類の項目は、そのファイルで名前が取れた種類だけ有効（取れない種類はグレー。ホバーに理由）。名前が1つなら右に薄字で出る。複数なら「…」。
- 名前が**1つ**の種類を押すと、そのまま検索する。**複数**の種類を押すと、選択ダイアログが開く（チェックした名前のOR。初期は全部未チェックで、1つもチェックが無いうちは「検索」がグレー）。
- 複数ファイルを選択して右クリックしたときは、「主要タグ検索」全体がグレー（1ファイルだけを選んで右クリックする）。
- 種類をまたいだ組み合わせ（例: 作者＋キャラ）の検索は無い。

### ワンアクションの動き

1. 検索タブへ移り、新モード（台帳全件）に切り替える。
2. 検索文字列を選んだ名前だけにする（空白を含む名前は `"…"` で囲む。複数は空白区切りで OR）。サイズ条件（最小・最大MB）は空にする。前回の入力が結果を黙って絞らないようにするため。
3. すぐに検索を開始する。履歴には、通常の新モードの検索と同じく条件が積まれる。

- 台帳（DB）が使えないときは、移動せずトーストで知らせる。
- 別の検索が実行中のときは、検索タブへ移って条件だけを入れ、開始せずにトーストで知らせる（検索は同時に1つだけ。終わってから「検索開始」を押す）。
- 検索語は名前の部分一致で、ファイル名の一致も拾う（新モード検索の仕様のまま）。名前が短いと、無関係なファイルも出うる。
- 実行は、描画が終わった後に行う（メニューのクリックは一覧の描画の途中で呼ばれ、その中で一覧を差し替えると範囲外参照になるため）。

## 名前の解決

右クリックした瞬間に1回だけ解決してキャッシュする（メニューを開いている間は読み直さない）。**種類ごとに**、次の順で取る。

1. ファイルに付いているタグ（DB）。その種類のカテゴリの要素名を使う。別名つきの要素（`A|B|C`）は1名として扱い、表示と検索は主表記（先頭の別名）。
2. DBにその種類が無いときだけ、ファイル名からの抽出（学習データ・タグ抽出ルールつき。zip は開かない）。

- 演者・キャラクター・パロディ元は、ファイル名からは、タグ抽出ルールで有効にしたときだけ出る。DBのタグからは常に取れる。
- 全種類がDBで埋まっているときは、ファイル名の抽出を行わない。
- 学習モデルが「無視」と判定した括弧・ルールで無効にされたものは、候補から除く。

## 主要タグ取得状況

サブメニュー末尾のボタンが、取得状況を表示する。

| 状態 | 表示 | 押せる |
|---|---|---|
| 高精度 | 主要タグ取得状況: メタデータから取得 | 押せない（グレー） |
| 簡易取得 | 主要タグ取得状況: ファイル名から簡易取得 | 押せる（案内を開く） |
| 取得不可 | 主要タグ取得状況: 取得不可 | 押せる（案内を開く） |

判定:
- 名前が1つも取れなければ**取得不可**（このときも「主要タグ検索」は開け、種類がすべてグレーで、このボタンだけ押せる）。
- 全種類がDBのタグ由来で、かつキャッシュの詳細フラグ（`cache.redb`）に ComicInfo.xml または meta.json があるときだけ**高精度**。
- それ以外は**簡易取得**。ファイル名由来が1つでも混ざれば、一番低い精度に合わせて簡易取得。
- 詳細フラグが info.txt のみ・無し・未確認（そのフォルダをまだ開いていない等）・対象外のときは、高精度の根拠にならない。記録が現物と一致しない（古い）ときも未確認として扱う。

案内ダイアログ（ボタンを押すと開く。題は「主要タグの取得状況について」）:
- 簡易取得用と取得不可用の2文面。括弧が無くても取得できる条件（メタデータがありタグ自動抽出で付与済み／メインカテゴリ等を手動設定し学習データに沿って抽出できる）や、正確に取得する方法（「現フォルダファイルのタグ自動抽出＆付与」の実行）を説明する。
- レイアウトは新検索の「注意点」ダイアログと同じ（最大幅440で折り返し、右上の×だけで閉じる）。

## 右クリックメニューのテーマ分け（エクスプローラー側）

見出し（太字・クリック不可）の下に、項目を左へインデントして並べる。テーマ間は区切り線。

| メニュー | 構成 |
|---|---|
| カード／リスト行 | ファイル設定（お気に入り詳細・ソート条件・しおり保存・見開き設定・スコアの設定）／検索（主要タグ検索）／ファイラーで開く（OS）／タグ学習／お気に入り整理（お気に入りタブのみ） |
| フォルダのセル（サブフォルダ・「↑」） | ファイラーで開く（OS）: 現在のフォルダをファイラーで開く・このフォルダをファイラーで開く |
| 一覧の余白 | ファイル設定（お気に入り詳細設定。常にグレー）／ファイラーで開く（OS。実・仮想フォルダのタブのみ） |
| 実ツリー | 仮想フォルダ（仮想フォルダに追加する。仮想タブ内のみ）／ファイラーで開く（OS）／表示（ソート条件設定） |
| 仮想ツリー | 仮想フォルダ（名前を変更・実フォルダ登録・実パスのサブフォルダを一括登録・フォルダ削除）／移動（実ツリーと同期・フォルダタブで開く）／ファイラーで開く（OS）／表示（ソート条件設定） |
| 仮想タブ中央のフォルダカード・「↑」 | ファイラーで開く（OS） |
| お気に入りフォルダ（お気に入りタブ左ペインの行） | お気に入り整理（プロパティの変更 (F2)・お気に入りフォルダの削除） |

- 「ファイラーで開く（OS）」は OS のファイラーを開く項目。アプリ内で別のタブへ移る項目（「フォルダタブで開く」など）は「移動」に分けている。
- 項目の名称を変えた:「現在のフォルダをファイラーで開く」「このフォルダをファイラーで開く」（旧: 現在のフォルダを開く／このフォルダを開く）、「移動先を指定して再紐付け」（旧: 移動先を指定して元ファイルを検索）、「実パスのサブフォルダを一括登録」「フォルダ削除」（旧: フォルダの実サブフォルダを一括登録／仮想フォルダ削除）。
- 項目「このフォルダを検索タブで開く」は、全メニューから削除した（新検索を主にするため）。旧モード本体（検索タブの新／旧の切り替えと、基点フォルダの指定）は残している。
- ビューアー側の右クリック（ツール枠のメニュー・画像上の保存系メニュー）は、テーマ化の対象外。
