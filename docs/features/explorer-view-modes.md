# エクスプローラーの表示モード（カード／リスト）と手動テスト手順

エクスプローラー中央部の表示を、サムネのカードと、1行1項目のリストで切り替える機能（U1）。
実装は [view_mode.rs](../../src/view_explorer/view_mode.rs)（モードの状態と保存）、
[list_view.rs](../../src/view_explorer/list_view.rs)（リストの描画）、
[selection.rs](../../src/view_explorer/selection.rs)（選択の規則）、
[panels.rs](../../src/view_explorer/panels.rs)（ボタン・カード・共通操作）。

## 仕様

### 切替ボタン

- パス行の左端に `[カード] [▼リストS] [一覧]` を横並びで置く。パス表示はその分だけ右へ寄る。
- 「▼リスト」は押すたびにサイズが循環する: S → M → L → ホバー → S。ラベルも `▼リストS` のように変わる。
  カードや他のモードから戻るときは、前回のリストのサイズで開く。幅は最長ラベルに固定（循環してもパスがずれない）。
- **「一覧」（文字のみ）は仕様未確定のため封印中**。ボタンは残してグレー表示・押せない。
  `TEXT_MODE_ENABLED`（view_mode.rs）を true にすると復活する。描画の実装（`layout_for` など）は残してある。
- モードは全タブ（実フォルダ・検索・お気に入り・仮想フォルダ）で共通の1つ。`nekoviewer.state` の
  `explorer_view_mode`（`"<mode>:<size>"`、例 `list:m`）に保存する。未知・欠落はカード・S。保存値が一覧ならカードに戻す。

### リストの列と行

- 列（左から）: 重複（空の枠。重複機能で埋める）／サムネ／名前／サイズ／更新日時／評価（未評価 or ★）／訪問回数。
  列は固定幅で、収まらないときは横スクロール。先頭に列見出しの行がある（まだ並べ替えには使えない）。
- 行の高さはサムネ設定（px）に対して S=25% / M=40% / L=60%（下限24px）。
- ホバー: 行は文字のみ（サムネ列なし）で、行にホバーするとポインタの横にサムネをポップアップする（遅延なし、画面端は反対側へ）。
- フォルダ（↑・サブフォルダ・仮想の↑・仮想フォルダ）も同じ列の行として、ファイルより前に並ぶ。リンク切れは名前の前に ⚠。
- 選択中の行は枠＋薄い塗り（生ファイルは赤、ZIPは青）。カーソル位置にはカーソルリング。
- 選択ファイルの詳細行（パス行の下の更新日時・サイズ・名前）は、カードのときだけ出す（リストは行が同じ情報を持つ）。
- リストは1列として扱う（キーボードの上下移動）。位置補正（`grid_anchor`）はリストでは働かない（U2で対応予定）。

### 選択の規則（カード・リスト共通。selection.rs）

- 青枠: 複数選択が空でないときは `multi_selected` だけを見る。空のときは単一選択。
- Ctrl+クリック: 選択に加える／外す。複数選択が1つになったら単一選択へ畳む。外した項目に枠が残らない。
  単一選択だけの状態で同じ項目を Ctrl+クリックすると解除できる。
- Shift+クリック: 起点から、クリックした項目までの範囲（フィルタ後の表示順で数える）。
- フォルダ（↑・サブフォルダ）は複数選択の対象外。「有効な行より手前」は最も近い有効行（先頭のファイル）に置き換える。
  - フォルダを Shift+クリック: 有効な起点（いま選択中の行）があれば、先頭〜その行を選択。無ければ先頭のファイルを新しい起点にする。
  - フォルダを通常クリックして選択が空になったときは、古い起点を捨てる（見えない起点から範囲を引かない）。
  - カーソルがフォルダにある状態でファイル行を Shift+クリック: 始点を先頭のファイルに置き換えて、先頭〜クリック行を選択する。

`cargo run`（debug）で行う。✓ 欄に記入して使う。

- [ ] ZIP・画像が20個以上あるフォルダと、サブフォルダが2つ以上あるフォルダを用意する。評価を付けたものを混ぜる（★4、★2.5、未評価）。
- [ ] 同じ内容を、仮想フォルダにも登録しておく（仮想フォルダの確認用）。

## 既知の割り切り（U2 以降）

- リストの列見出しをクリックしても並べ替えられない。
- キーボードでカーソルを動かしたときの、リストでのスクロール追従がない（行の高さが違うため、カード用の計算が合わない）。
- リスト↔カードの切替時のスクロール位置の補正がない。
- 行は全件を並べる（仮想スクロールなし）。数万件のフォルダでは重くなりうる。
- リストにはお気に入り・保存設定・赤×・ネットワーク切れのマーカーがまだ出ない。
- キーボードの Shift+矢印でフォルダに乗ったときの起点は、従来の規則のまま。
