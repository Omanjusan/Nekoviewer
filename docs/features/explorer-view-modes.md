# エクスプローラーの表示モード（カード／リスト）と手動テスト手順

エクスプローラー中央部の表示を、サムネのカードと、1行1項目のリストで切り替える機能（U1・U2）。
実装は [view_mode.rs](../../src/view_explorer/view_mode.rs)（モードの状態と保存）、
[list_view.rs](../../src/view_explorer/list_view.rs)（リストの描画）、
[selection.rs](../../src/view_explorer/selection.rs)（選択の規則）、
[list_columns.rs](../../src/view_explorer/list_columns.rs)（列幅）、
[layout_anchor.rs](../../src/view_explorer/layout_anchor.rs)（レイアウト変更時の位置補正）、
[panels.rs](../../src/view_explorer/panels.rs)（ボタン・カード・共通操作）。

## 仕様

### 切替ボタン

- パス行の左端に `[カード] [▼リストS] [一覧]` を横並びで置く。パス表示はその分だけ右へ寄る。
- 「▼リスト」は押すたびにサイズが循環する: S → M → L → ホバー → S。ラベルも `▼リストS` のように変わる。
  カードや他のモードから戻るときは、前回のリストのサイズで開く。幅は最長ラベルに固定（循環してもパスがずれない）。
- **「一覧」（文字のみ）は仕様未確定のため封印中**。ボタンは残してグレー表示・押せない。
  `TEXT_MODE_ENABLED`（view_mode.rs）を true にすると復活する。描画の実装（`layout_for` など）は残してある。
- モードは全タブ（実フォルダ・検索・お気に入り・仮想フォルダ）で共通の1つ。`nekoviewer.state` の
  `explorer_view_mode`（`"<mode>:<size>"`、例 `list:m`）に保存する。未知・欠落はカード・S。保存値が一覧ならカードに戻す。

### リストの列と行

- 列（左から）: 重複（空の枠。重複機能で埋める）／サムネ／名前／サイズ／更新日時／評価（未評価 or ★）／訪問回数。
  収まらないときは横スクロール。列見出しの行は本体の縦スクロールの外に固定で置き、横スクロールには同期する。
- 行の高さはサムネ設定（px）に対して S=25% / M=40% / L=60%（下限24px）。
- ホバー: 行は文字のみ（サムネ列なし）で、行にホバーするとポインタの横にサムネをポップアップする（遅延なし、画面端は反対側へ）。
- フォルダ（↑・サブフォルダ・仮想の↑・仮想フォルダ）も同じ列の行として、ファイルより前に並ぶ。リンク切れは名前の前に ⚠。
- 選択中の行は枠＋薄い塗り（生ファイルは赤、ZIPは青）。カーソル位置にはカーソルリング。
- 選択ファイルの詳細行（パス行の下の更新日時・サイズ・名前）は、カードのときだけ出す（リストは行が同じ情報を持つ）。
- リストは1列として扱う（キーボードの上下移動）。カーソルを動かすと、その行が画面内に収まる最小の量だけスクロールする
  （`scroll_to_row`。カードのピッチではなくリストの行高と隙間で計算）。
- 仮想スクロール: 全行ぶんの高さを一度だけ確保し、見えている行（前後1行の余裕つき）だけの当たり判定・描画を行う。
  行の当たり判定のIDは行ごとの子UIの下に置く（eguiのデバッグ警告「矩形のIDが変わった」を避けるため。release では出ない警告）。
- 縦のグリッド線: 列どうしの区切りに細く薄い線を、表示領域の全高に引く（横線は引かない）。

### 列見出し（固定表示）

- **クリックソート**（メニューバーのソートと状態を共有する。見出しで変えるとボタンの押し下げ表示も連動する）。
  - 名前・サイズ・更新日時（主ソート）: 別の列を押すとその軸に切り替え（昇降はそのまま）、同じ列をもう一度押すと昇降を反転。
  - 評価・訪問回数（副ソート）: 押すとON（降順）→ もう一度で昇順 → さらに押すとOFF。別の評価系の列を押すとそちらがON（降順）。
  - 並べている列には ▲（昇順）／▼（降順）が付き、文字が強調される。重複・サムネ列はソート対象外。
  - ソートすると、メニューバーのソートと同じく、複数選択と範囲選択の起点は解除される。
- **列幅の変更**: サムネ列を除く6列（重複・名前・サイズ・更新日時・評価・訪問回数）の境界をドラッグして変えられる。
  - ツマミは表示しない。見出しの境界にホバーしたときだけ、カーソルが左右リサイズになり、その境界線が太くなる。
  - 境界をダブルクリックすると、その列が既定幅に戻る。最小幅あり（重複20・名前80・サイズ50・更新日時80・評価60・訪問回数40）。上限1200px。
  - 全モード・全タブ共通の1組を `nekoviewer.state` の `explorer_list_cols`（カンマ区切りの6つの整数）に保存する。壊れた値は全て既定幅。

### レイアウトが変わったときの位置補正（layout_anchor.rs）

- カード↔リスト、リストのサイズ（S/M/L/ホバー）、サムネ設定の変更で、見ていた位置を保つ。
- 基準: 選択（カーソル）項目が一部でも見えていればそれを同じ画面上の高さに保つ。見えていなければ上端の行の先頭の項目。見切れ量も復元する。
- 列数だけが変わる補正（ウィンドウ幅・タグパネル）は従来どおり `grid_anchor.rs`（カードのみ）。件数が変わったとき（別フォルダ・フィルタ）は補正しない。

### 選択の規則（カード・リスト共通。selection.rs）

- 青枠: 複数選択が空でないときは `multi_selected` だけを見る。空のときは単一選択。
- Ctrl+クリック: 選択に加える／外す。複数選択が1つになったら単一選択へ畳む。外した項目に枠が残らない。
  単一選択だけの状態で同じ項目を Ctrl+クリックすると解除できる。
- Shift+クリック: 起点から、クリックした項目までの範囲（フィルタ後の表示順で数える）。
- フォルダ（↑・サブフォルダ）は複数選択の対象外。「有効な行より手前」は最も近い有効行（先頭のファイル）に置き換える。
  - フォルダを Shift+クリック: 有効な起点（いま選択中の行）があれば、先頭〜その行を選択。無ければ先頭のファイルを新しい起点にする。
  - フォルダを通常クリックして選択が空になったときは、古い起点を捨てる（見えない起点から範囲を引かない）。
  - カーソルがフォルダにある状態でファイル行を Shift+クリック: 始点を先頭のファイルに置き換えて、先頭〜クリック行を選択する。

## 既知の割り切り

- 「一覧」（文字のみ）は仕様未確定のため封印中。ボタンはグレーで押せない（`TEXT_MODE_ENABLED`）。描画の実装（`layout_for`）は残してある。
- リストにはお気に入り・保存設定・赤×・ネットワーク切れのマーカーがまだ出ない（重複機能と合わせて設計する）。
- 重複の列は枠のみで、中身は重複機能で埋める。
- キーボードの Shift+矢印でフォルダに乗ったときの範囲選択の起点は、従来の規則のまま（マウスの規則とは別）。
- 横スクロールの位置は、レイアウト変更時の位置補正の対象外。
- 数万件規模では、キーボード操作のために毎フレーム全エントリを組み立てる処理（`grid_entries()`）が残っている（カードにも元からある）。
- 見出しの横位置は直前のフレームの横スクロール量を使うので、横スクロールバーを素早く動かすと1フレーム遅れて追従する。
