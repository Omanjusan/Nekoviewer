# 重複マーカーと類似ファイル一覧

同じ内容（FP一致）のファイルが複数あることを、ファイルを触らずに警告する機能。
きっかけは、新規ダウンロードのつもりで保存したアーカイブが、既存ファイルの評価・タグを黙って引き継いだこと。
ファイル操作はしない。警告と、見比べ・削除の判断材料を出すだけで、削除はユーザーがファイラーで行う。

実装は [duplicate_marker.rs](../../src/duplicate_marker.rs)（台帳）、
[dup_marker_ui.rs](../../src/view_explorer/dup_marker_ui.rs)（アイコン・ポップアップ）、
[marker_probe.rs](../../src/view_explorer/marker_probe.rs)（存在確認・遡及検出・類似グループの収集）、
[marker_compare.rs](../../src/view_explorer/marker_compare.rs)（完全比較）、
[similar_view.rs](../../src/view_explorer/similar_view.rs)（類似ファイル一覧）、
[identity_worker.rs](../../src/view_explorer/identity_worker.rs)（ID解決からの記録）。
ファイルIDの仕組みは [file-identity.md](file-identity.md)。
FPが違っても見た目が似ているファイルは、サムネの比較で別に拾う（[similar-image-marker.md](similar-image-marker.md)）。

## マーカーの種類

| 種類 | いつ付くか | 表示 |
|---|---|---|
| 移動 | ID解決が「移動」と判定したとき（旧パスが消えている） | 青の矢印。一時的 |
| 再取得 | 同じ内容の現存ファイルが他にあるとき | 橙の二重四角。永続 |
| 旧ファイル側 | 再取得マーカーの重複先になっているファイル | 再取得の薄い同形 |
| 消去済み | ユーザーが「正常として消した」再取得 | 灰色。「消去済みも」を入れたときだけ出る |

- 1ファイルに付くマーカーは最大1つ。移動と再取得が重なったら再取得が優先される。
- **移動マーカー**: 表示領域に入ると印が付き、フォルダを離れるか終了すると書き込まれ、次に開いたときに消える。
  検索・お気に入りの横断一覧では印を付けない。
- **再取得マーカー**: ユーザーがファイルを消すか、正常として消すまで残る。重複先は、持ち主よりIDの小さい現存ファイル（最大16件）。
- 付く経路は2つ。(1) ID解決が、評価などのデータを持つ現存ファイルから複製したとき。
  (2) **遡及検出**: フォルダを開き、ID解決が済んだ時点で、そのフォルダのファイルについて同じFPの現存ファイルを探す。
  現存ファイルが2つ以上あれば、IDの大きい方（後から登録された方）が再取得側になる。データの有無は問わない。
  別フォルダにある新しい側にも付く。消去済みの印は消さず、同じ検出を繰り返しても増えない。
- 重複先が全て消失と確認できた再取得マーカーは、表示から外れる（台帳は触らない。重複先が移動しただけの場合に、取り返しがつかなくなるため）。
  オフラインの重複先は消えたと断定しない。確認はフォルダを読み込むたびに1回、専用スレッドで行う。

## エクスプローラーでの見え方

- カード: 上辺の左右中央にアイコン。リスト: 左端の「重複」列にアイコン。
- 下段フィルタ行の「重複あり」（自身にマーカーがあるファイルだけ）と「消去済みも」。どちらも保存しない。
  お気に入り・検索の横断一覧では使えない。
- リストの「重複」見出しのクリックで、マーカー付きを検出日時の新しい順で先頭に寄せる（他のソートとは別軸）。
- 新しく検出されたときは、トーストで件数を出す。
- アイコンのホバーに説明が出る。移動以外は「クリックすると、同じ内容のファイルだけを一覧で見られます」を添える。
- **クリック**: 移動マーカーは説明のポップアップを出す。それ以外（再取得・旧ファイル側・消去済み）は類似ファイル一覧を直接開く。

## 類似ファイル一覧

現在のタブの中で、同じ内容のファイルだけを並べる一時ビュー。タブも検索履歴も触らない。

- 並べるのは、入口のファイルと同じFPの現存ファイル全て（件数の上限なし）。消失・オフラインは一覧に出さず、
  上部の「確認できないファイルが別にN件あります」にホバーすると、パスと状態が出る。
- 画面の最上部に、青系の告知バー「類似ファイルビュー」を出す。
- 開くとリスト表示になり（戻ると元のモードへ）、「場所」列（フルパス。長いときは先頭を省略）と「完全比較」列が付く。
- 入口のファイルは最上位に固定し、背景色を変える。残りはソート設定に従う。
- 「重複」列は「基準」列になる（ラジオ式で、常に1つ）。カードは上辺中央の●○。基準は完全比較の基準で、
  既定は最古のID。付け替えると、実行中・順番待ちの比較は取り消され、結果は基準ごとに残る。
- 上部バー: 「← 類似ビューから戻る」／件数／「全て完全比較」／「更新」／「この組を正常として消す」。
  - **全て完全比較**: 基準と他の全てを、専用スレッドで1組ずつ先頭から直接バイト比較する。1MBずつ読み、不一致で打ち切る。
    サイズが違えば読まずに不一致。開始時と終了時にサイズ・更新日時を確認し、変化していたら「変化で中断」。
    結果は行（カードは上辺中央）のバッジに出す。実行中は「全て中止」。終わると、トーストを1回出す。一覧を閉じても続く。
  - **結果の保持**: 一致・相違だけをアプリ終了まで保持する。台帳には書かない。サイズ・更新日時が変わったら破棄する。
  - **更新**: 同じ組を集め直す。消えたファイルは外れ、基準が消えていれば最古のIDに戻る。
  - **この組を正常として消す**: 一覧のファイルが持つ再取得マーカーを全て消去済みにして、元のフォルダへ戻る。
  - ウィンドウにフォーカスが戻ると、一覧のファイルの存在を確認し、消えていたら行を薄くする（外すのは「更新」）。
- 戻ると、入口にしていたファイルを選び直し、画面の中央へスクロールする。
- 一覧を抜ける操作（フォルダ移動、他のタブ、お気に入り・検索、仮想ノード）は、全て一覧を閉じて元の表示モードへ戻す。
- カードの右クリックメニュー「ファイラーで開く」で、削除したいファイルの場所を開ける。

## 台帳（redb）

- `duplicate_marker_v1`: ファイルID → マーカー（種類・重複先・フラグ・検出日時）。フラグは bit0 表示領域に入った／bit1 消去済み／
  bit2 更新日時が重複先と同じ。bit3 は旧版が「完全一致を確認済み」に使っていたが、今は使わず、読むときは無視する。
- `duplicate_marker_target_v1`: 重複先ID → 持ち主ID（逆引き。旧ファイル側の判定用）。
- どちらも最初の追加で作る（旧DBは起動だけでは変えない）。`delete_id`・ID掃除・孤児の引き継ぎに連動して消える。

## 制限

- FPは「サイズ＋サンプルのハッシュ」なので、窓の外だけが違うファイルは同じFPになる。マーカーは「簡易照合で一致」であり、
  断定ではない。断定したいときは完全比較を使う。
- 移動マーカーは旧ファイルが無く、類似ファイル一覧にも完全比較にもならない。
- 完全比較は基準との組だけで、基準以外のファイル同士は比べない。
- 引き継ぎの解除（記録を外して空にする）は作らない。
