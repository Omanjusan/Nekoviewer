# カード帯（サムネカード下部の情報帯）の設定

サムネカード下部の帯に何を出すかを決める機能。メニューバーの `カード帯設定` ボタンから設定ダイアログを開く
（旧「情報」「情報2」の2つの循環ボタンを1個に集約）。

- 導線は2つ: **従来方式**（Classic mode。ワンタッチの循環ボタン）と **カスタム**（要素を積んで書式を作る）。
  どちらを実採用するかを選ぶ。両方の内容は保存され、切り替えても消えない
- 実カードの帯は、カスタム有効なら**カスタムの帯だけ**を描く（従来方式の帯は出さない。
  要素が空なら何も出さない）。従来方式有効なら従来の帯を描く
- 設定が反映されるのは、ダイアログで**確定**したとき。キャンセル・Esc・枠外クリックは何も変えない

## ダイアログ

- 閉じるのは確定／キャンセルのみ（✕なし）。モーダルで、背面は操作できない。Esc・枠外クリックはキャンセル扱い
- 幅は窓幅-60pxを 480〜660px に収める。左右の欄は同幅で、中央線はダイアログの中央
- 上段の左右の**見出しが排他の切替ボタン**: `従来方式` / `カスタム`。押した側がアクティブ（ハイライト）になり、
  非アクティブ側の欄はグレーアウトして内容を保持する。確定は両方を保存し、アクティブ側を実採用する
- 下段は共通の**サンプル帯**（疑似カード＋帯）。最後に切り替えた側の内容を出し、見出し横に「従来方式の内容／カスタムの内容」。
  実カードと同じ描画（`card_band_paint::paint_band`）を使い、ファイル名などは固定のダミー
- サンプル表示エリアの右上に**透過度ボタン**（後述）
- 右下: 確定 / キャンセル

### 従来方式（左）

- ボタン2個。1つ目は情報（`OFF → 名前 → 名前+日付 → 名前+日付+容量`、`CardInfoMode`）、
  2つ目は評価（`OFF → ★ → 回数 → ★+回数`、`CardRatingMode`）。押すたびにサンプル帯が変わる
- 従来の帯の描画（情報行は左寄せ・評価行は中央寄せ・ホバーでマーキー）は変更していない

### カスタム（右）

- 要素ボタンを押した順にスタックする。各項目に `[寄せ]` と `X`。差し込み・並べ替えは無し（削除のみ）
- 要素（9個）: 日付／タイトル／サイズ／評価点★／評価点数値／訪問回数／空白／改行／区切りバー
  - タイトル = 拡張子付きのファイル名。空白 = 半角1個ぶん（連続で積めば広がる）。
    区切りバー = 行の高さいっぱいの縦線（文字色・約1px）
  - 評価点★ = 星の描画、評価点数値 = 小数1桁（例 3.5）
  - 日付は設定ダイアログの日付書式（`card_date_format`）に従う
- 寄せ属性: `未設定 → 左 → 中央 → 右 → 未設定` のトグル。未設定も「未設定」と明示する
- 上限: 要素24個・行6行。`要素制限数 n/24　行制限数 n/6` を表示し、上限に達した要素ボタンはグレーアウト
- 確定時に正規化する: 先頭・末尾の改行を削除、連続改行を1つにまとめる（カスタム側のみ。従来方式の選択はそのまま）

## 配置ルール（カスタム）

- 行は改行で分かれる。すべての行で上下中央。左右は寄せ属性による3ゾーン（左・中央・右）
- 明示指定（左／中央／右）を最優先で置く。未設定は左ゾーンの**明示左の後ろに**書式順で続く
- 幅が足りないときの優先は 左 → 右 → 中央。溢れた側を切り詰める（中央は左右の間に収まるようずらす）。
  ホバー中のカードでは、溢れたゾーンの内容だけが往復スクロールする（両端0.6秒静止、約42px/秒）。★は縮小しない
- データ不在時の表示は従来方式を踏襲: 評価の要素は、生画像が「-」、未評価が「未評価」、評価ありが星／小数1桁。
  訪問回数は「訪問回数：XX回」、日付・サイズが未取得なら空
- 日付・サイズ・評価は、書式がそれを使うときだけ取得する（可視カードぶんの遅延取得）

## 帯の透過度

- サンプル表示エリアの右上のボタン `透過度 N%`。押すたびに10%ずつ変わる（0 → 10 → … → 100 → 0）
- 0% = 不透明、100% = 帯の背景が完全に透明（文字だけ残る）。既定40%（従来の黒・アルファ150にほぼ等しい）
- 従来方式の帯・カスタム帯の両方に効く。サンプルには即時反映し、実カードへは確定後に反映する

## 保存（state）

`nekoviewer.state` のキー。従来のキー（`card_info_mode` / `card_rating_mode`）は維持する。

| キー | 値 |
|---|---|
| `card_band_active` | `classic` / `custom`。未知値・キー無しは `classic` |
| `card_band_custom` | カスタム書式。`要素ID[:寄せ]` のカンマ区切り。例 `title:l,space,date:r,nl,stars:c` |
| `card_band_transparency` | 透過度(%)。10刻みへ丸める。壊れた値・キー無しは 40 |

- 要素ID: `date` `title` `size` `stars` `score` `visits` `space` `nl` `bar`。寄せ: `l` `c` `r`（未設定は省略）
- 未知の要素は読み捨て、未知の寄せは未設定。上限を超えていても読み込み時に正規化して収める（前方互換）
- 一度リリースしたIDは変更しない

## 手動テスト

1. メニューバーに `カード帯設定` ボタンが1個あり、旧「情報」「情報2」は無い。押すとダイアログが開く（Enterでも、キー移動のカーソルが乗っていれば開く）
2. ダイアログに ✕ が無い。Esc・枠外クリックでキャンセル（実カードは変わらない）。確定／キャンセルのボタンも効く
3. 見出し `従来方式` / `カスタム` が排他の切替ボタン。押した側がハイライトされ、もう一方の欄がグレーアウトする。サンプルも切り替わる
4. 従来方式: ボタン2個を押すたびサンプルが変わる。確定すると実カードの帯が同じ内容になる（従来の帯と同じ見え方）
5. カスタム: 要素ボタンで積める。`X` で途中の項目も削除でき、差し込み・並べ替えはできない。寄せボタンが 未設定→左→中央→右→未設定
6. 例「タイトル(右)・空白(中央)・評価点(左)・訪問回数(左)」を1行に積むと、左=評価点+訪問回数、中央=空白、右=タイトルで並ぶ
7. 未設定の要素は、明示の左の後ろに積んだ順で続く。改行で行が分かれ、各行は上下中央
8. 要素24個・行6行の上限で、該当ボタンがグレーアウトし、`要素制限数` / `行制限数` の表示が正しい
9. 確定すると、先頭・末尾の改行が消え、連続改行が1つになる（再度開いて確認）
10. 幅の足りない行: 左が優先、次に右、中央が切り詰められる。ホバーすると溢れたゾーンだけスクロールする
11. 区切りバーが行の高さいっぱいの縦線で出る。評価点★が星、評価点数値が `3.5` の形式
12. 生画像のカードで評価の要素が「-」、未評価のアーカイブで「未評価」
13. **バグ回帰**: 従来方式の帯が出ている状態で、カスタムに切り替え、何も積まずに確定する → 帯が何も出ない。従来方式へ戻して確定すると従来の帯が復活する
14. 従来方式で確定した後、再度開いても、カスタム側の積んだ内容が残っている（切替で消えない）
15. 透過度ボタンが、サンプル表示エリアの右上にある。押すたびに 40→50→…→100→0→10 と変わる。サンプルの帯の濃さが変わる
16. 透過度は確定するまで実カードに反映されない。確定後は、従来方式の帯にもカスタム帯にも効く
17. 再起動後も、有効な導線・カスタム書式・透過度・従来方式の選択が残っている
18. 旧state（`card_band_*` キー無し）で起動すると、従来方式・透過度40%で、これまでと同じ見え方
19. 表示言語を英語・中国語にすると、帯ボタン・ダイアログの全文言が切り替わる（従来方式は `Classic mode`）
