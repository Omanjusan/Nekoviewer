# タグ自動取得の学習（判定の学習）

「現フォルダ内タグ情報取得」の、括弧の種別判定（作者／グループ／イベント／言語／無視）を、ユーザーが振り分けたファイル名から学習して改善する機能。

## 仕組み
- ファイル名の括弧 `(...)` `[...]` を1つずつトークンにし（`src/tag_features.rs`）、括弧の種類・位置・入れ子・文字種・長さ・形・辞書語を特徴量にする。**名前そのものは特徴量に入れない**（名前は覚えない）
- 学習データは「ファイル名＋正解ラベル」。設定フォルダの `nekoviewer_tag_learning.json`（全フォルダ共通）。ラベルを書かない括弧は「無視」として学習する（`src/tag_learning.rs`）
- モデルは外部依存なしの多クラスロジスティック回帰。乱数を使わず、同じ学習データなら同じモデルになる（`src/tag_model.rs`）
- `[A (B)]` の外側・内側は、違う種別になる組み合わせから、確率の積が最大のものを選ぶ
- 候補生成（`build_candidates_with`）で、既存マスタに完全一致があればマスタを優先する。確信度0.75未満の作者・グループは「未確定」扱い
- モデルが「無視」と判定した括弧は、候補から消さず、**未採用・要確認**（`Candidate.review`）で残す
- 学習データが無い、または「学習結果を使う」がOFFのときは、従来のルールだけで判定する

## 画面
- タグパネル: 「現フォルダ内タグ情報取得」の下に、`[タグ学習…]` ボタン、学習済み件数、学習結果を使う/使わないの切替
- タグ学習窓: 学習済み件数、目安の一致率（10件以上で表示・学習データ内の5分割検証・件数が少ないと揺れが大きい）、学習結果を使うチェック、10/20/30件のラジオ、`学習を始める`、`学習データを見る…`、`全消去してやり直す`（確認つき）
  - 10件=手軽だが不安定／20件=バランス／30件=手堅い（手間は中程度）
  - サンプルは現在のフォルダから、括弧の形が違うものを優先して選ぶ（学習済みと括弧の無いファイルは除く）
- ラベル窓: 1ファイル2行（上にファイル名、下に括弧ごとの種別ドロップダウン）。初期値は、モデルがあればモデルの予測、無ければ従来ルールの結果。直した行は自動で確認済み。確認済の行だけで学習する
- 学習データ閲覧窓: ファイル単位の削除、ラベル単位の削除（`×`）
- 右クリック: ファイルのメニューに `タグ学習に追加…`（そのファイル1件のラベル窓。学習済みなら保存済みのラベルが初期値。括弧の無いファイル名は押せない）
- 初回案内: 学習データが無く、案内を止めていないときに「現フォルダ内タグ情報取得」を押すと、案内ダイアログを1回出す（件数ラジオ／`学習する`／`今回は学習せず取得`／`今後このご案内を表示しない`）。学習したら、続けて取得を始める
- 設定窓（エクスプローラータブ）: 「学習結果を使う」のスイッチ（学習窓のチェックと同じ値）

## 永続設定（state）
- `app_tag_learning_use=true|false`（既定 true）
- `app_tag_learn_intro_hidden=true|false`（既定 false）

## 計測・目視用のテスト（`cargo test`）
- `tag_corpus::baseline_on_synthetic`: 合成コーパス（`tests/data/tag_corpus_synthetic.tsv`）に対する現行ルールの一致率
- `tag_eval::learning_curve_on_synthetic`: 擬似ライブラリの学習曲線（10〜50件）。擬似ライブラリは想定した命名規則から作ったもので、実ライブラリの精度ではない
- `NEKO_CORPUS=<tsv> cargo test baseline_on_file -- --ignored --nocapture`: 実コーパスの一致率と外れ一覧
- `NEKO_CORPUS=<tsv> cargo test learning_curve_on_file -- --ignored --nocapture`: 実コーパスの学習曲線・5分割検証
- `NEKO_SCAN_DIR=<dir> NEKO_CORPUS_OUT=<file> cargo test make_corpus_template -- --ignored --nocapture`: ファイル名から、現行ルールの結果を初期値にしたラベル雛形を出す
- `NEKO_CORPUS=<tsv> NEKO_LEARN_OUT=<設定フォルダ> cargo test export_corpus_as_learning_data -- --ignored --nocapture`: コーパスを学習データとして書き出す（既存の学習データは上書き）
- 実名のコーパスは `test/tag_corpus/` に置く（`/test` は gitignore 済み）

## 手動テスト
1. 括弧のあるアーカイブが入ったフォルダで、`タグ学習…` を押すと学習窓が開く（未学習・目安は「10件以上で表示」）
2. 件数ラジオを選び `学習を始める` → ラベル窓にファイル名と括弧ごとのドロップダウンが並ぶ。初期値は従来ルールの結果
3. ドロップダウンを変えた行のチェックが自動で入る。`すべて確認済にする` で全行にチェックが入る
4. 確認済が0件のとき `学習する` は押せない。1件以上で押せ、ホバーに「確認済のN件だけで学習」と出る
5. `学習する` でトーストが出て、学習窓に戻り、学習済み件数が増える
6. 10件以上学習すると、目安の一致率が出る
7. 学習後に `現フォルダ内タグ情報取得` を押し、確認ウィンドウの作者／グループ／イベントの判定が学習内容に沿って変わる
8. `学習結果を使う` をOFFにして取得すると、従来のルールの結果に戻る（学習データは残る）。設定窓のスイッチと連動する
9. `学習データを見る…` で一覧が出る。ラベルの `×` でそのラベルだけ、`削除` でそのファイルが消える
10. `全消去してやり直す` → 確認 → `消去する` で学習データが空になり、状態テキストが「未学習」に戻る
11. 括弧のあるファイルを右クリック → `タグ学習に追加…` で1件のラベル窓が開く。学習すると窓が閉じる。括弧の無いファイルでは押せない
12. 学習済みのファイルで `タグ学習に追加…` を押すと、保存済みのラベルが初期値になる
13. 学習データが無い状態で `現フォルダ内タグ情報取得` を押すと案内が出る。`今回は学習せず取得` で取得が始まる。`学習する` → ラベル付け → `学習する` で、学習後に取得が始まる。`今後このご案内を表示しない` にチェックすると、次回から案内が出ない
14. 学習窓が開いている間、エクスプローラーのキー操作が効かない
15. アプリを再起動しても、学習データ・学習結果を使う設定・案内の非表示が保たれる
16. 「ライト」テーマで、学習窓・ラベル窓の文字が読める
