# ツールボックスのキー割当

ビューアーのツールボックス（ツールパレット）のボタンに、キーアサイン設定タブとは別の導線で
キーを割り当てる機能。ビューアー専用。

## 使い方

1. ツールボックスのマスを右クリック →「ボタン名称の変更」の下の「キー割当」
2. ダイアログで割り当てたいキーを押す（枠の中に表示される）
   - 修飾キーは枠の左にある SHIFT／CTRL／ALT のトグルで指定する。物理的に押した修飾キーは無視
   - 「割当解除」で枠を「割当なし」にし、保存すると割り当てが消える
   - Esc は割り当てできない（押しても何も起きず、ダイアログも閉じない）
3. 「保存」で確定。「キャンセル」なら何も変わらない。開いたときと同じ内容で保存した場合も何もしない

### 衝突時

ビューアーのキーアサイン（ページ送り等）や、ツールボックスの別機能と同じキーを押すと、
赤字で「○○機能とキー割当が衝突しています」と表示され、保存ボタンが「上書き」に変わる。
上書きすると、衝突相手の割り当ては外れる。キーアサイン側の既定キーだった場合は
「割り当てなし」（既定キーも無効）になり、設定タブのキーアサイン一覧にもそう表示される。
リセットボタンで既定キーに戻せる。

## 挙動

- 割り当ての単位は **機能**（マスの位置ではない）。マスを入れ替えてもキーは機能について回る
- キーが効くのは、その機能がツールボックスに置かれている間だけ。同じ機能を複数マスに置いた場合は先頭のマスを実行する
- ツールボックスが非表示・自動ハイド中でもキーは効く。ダイアログ型（画像フィルタ）はキーで開閉し、非表示ならツールボックスを表示に戻す
- 文字入力中（ボタン名称の変更など）は発火しない
- ダイアログ表示中は、背面のビューアーのキー・ホイール・クリック操作を止める
- ダイアログの見出しはマスのカスタム名（未設定・空なら既定名）

## 保存形式

`keymap.ini` の `[keymap]` セクションに、機能の永続化ID（`slot_content_to_id` の値）で保存する。

```
palette.toggle:magnifier.keyboard = ctrl+M
reader.JumpFirstPage.keyboard = none   # 上書きで外された既定キー
```

`none` は「既定キーも含めて割り当てなし」。値なし（行が無い）は既定キーのまま。

## 設定タブとの関係

- 設定タブのキーアサインで、ビューアーのアクションにキーを割り当てると、ツールボックス側との衝突も
  警告に出る（設定タブ側は従来どおり「重複を登録して警告」で、相手の割り当ては外さない）
- 設定ダイアログはツールボックスの割り当てを編集しない。ダイアログを開いている間にビューアー側で
  保存された割り当ては、設定ダイアログの保存で巻き戻さない
